# [Lv1] 소수 찾기

> **유형:** `#수학` `#알고리즘` `#에라토스테네스의체` 
> **링크:** [12921](https://school.programmers.co.kr/learn/courses/30/lessons/12921)

## 📝 문제 요약
1부터 입력받은 숫자 `n` 사이에 있는 소수의 개수를 반환하는 함수, solution을 만들어 보세요.

## 💡 접근/풀이 방식
### 1. 제곱근 최적화
- 소수를 판별할 때 전부 판별하면 수가 커지고 계산 양도 많기에, 약수의 대칭성을 이용하여 `나머지 계산 시 수의 제곱근 <= 판별하려는 소수`로 조건을 맞추면 연산을 줄일 수 있다.
### 2. 알고리즘 : 에라토스테네스의체
- 소수를 판별할 때 쓰는 알고리즘으로, 그 소수의 모든 배수를 배열에서 지워나가는(체로 거르는) 방식이다.

## 💻 풀이 코드 (C#)
### 1. 제곱근 최적화
```C#
public class Solution {
    public int solution(int n) {
        int answer = 0;
        
        for(int i = 1; i <= n; i++)
        {
            if(IsPrime(i))
                answer++;
        }
        return answer;
    }
    
    // 소수 판별
    private bool IsPrime(int n) {
        if (n < 2) return false;
        
        for (int i = 2; i * i <= n; i++) {
            if (n % i == 0) 
                return false;
        }
        return true;
    }
}
```
### 2. 알고리즘 : 에라토스테네스의체
```C#
public class Solution {
    public int solution(int n) {
        int answer = 0;
        
        // 소수 여부를 체크할 배열 생성(true면 소수)
        // 인덱스를 직관적으로 쓰기 위해 n + 1 크기로 할당
        bool[] isPrime = new bool[n + 1];
        
        // 처음엔 0, 1을 제외한 모든 수를 소수라고 가정
        for (int i = 2; i <= n; i++) 
            isPrime[i] = true;
        
        for (int i = 2; i * i <= n; i++) 
        {
            if (isPrime[i]) 
            {
                // i가 소수라면, i의 배수들을 모두 소수가 아니라고(false) 지움
                // i * i 부터 시작하는 이유는 그 이하의 배수들은 이미 이전 단계에서 지워졌기 때문
                for (int j = i * i; j <= n; j += i) 
                    isPrime[j] = false;
            }
        }
        
        // 최종적으로 true(소수)로 남아있는 개수 카운트
        for (int i = 2; i <= n; i++) 
            if (isPrime[i]) answer++;
        
        return answer;
    }
}
```
