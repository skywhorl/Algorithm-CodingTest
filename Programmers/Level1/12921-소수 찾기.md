# 소수 찾기
### [Lv.1 - 12921](https://school.programmers.co.kr/learn/courses/30/lessons/12921)

## 문제
1부터 입력받은 숫자 `n` 사이에 있는 소수의 개수를 반환하는 함수, solution을 만들어 보세요.

소수는 1과 자기 자신으로만 나누어지는 수를 의미합니다.
(1은 소수가 아닙니다.)
## 풀이
- 소수를 판별할 때 약수의 대칭성을 이용하여 `나머지 계산 시 수의 제곱근 < 판별하려는 소수`로 조건을 맞추면 검산을 덜하게 된다.

``` C#
public class Solution {
    public int solution(int n) {
        int answer = 0;
        
        for(int i = 1; i <= n; i++)
        {
            if(IsPrime(i))
                answer++;
        }
        return answer;
    }
    
    // 소수 판별
    private bool IsPrime(int n) {
        if (n < 2) return false;
        
        for (int i = 2; i * i <= n; i++) {
            if (n % i == 0) 
                return false;
        }
        return true;
    }
}
```
