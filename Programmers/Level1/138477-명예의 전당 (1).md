# [Lv1] 명예의 전당 (1)

> **유형:** `#우선순위큐` `#배열` `#정렬`
> **링크:** [138477](https://school.programmers.co.kr/learn/courses/30/lessons/138477)

## 📝 문제 요약
매일 1명의 가수가 노래를 부르고, 지금까지 출연한 가수들의 점수 중 상위 `k`번째 이내의 점수들을 '명예의 전당'에 올립니다. 
매일 발표되는 명예의 전당의 최하위 점수를 배열에 담아 반환해주세요.
## 💡 접근/풀이 방식
최솟값을 계속해서 추적해야 하기에 다음과 같은 정렬 방식을 사용할 수 있다.
### 1. `List.Sort()` 활용
- `Sort()`로 오름차순 정렬을 하면 인덱스 0번째는 가장 작은 수가 된다.
### 2. `PriorityQueue` 활용
- 최솟값을 가장 빠르게 찾아낼 수 있는 자료구조다(Min-Heap).
- 내부적으로 가장 작은 값이 위로 오도록 정렬이 되어 있다.

## 💻 풀이 코드 (C#)
### 1. `List.Sort()` 활용
```C#
using System;
using System.Collections.Generic;

public class Solution {
    public int[] solution(int k, int[] score) {
        int length = score.Length;
        int[] answer = new int[length];
        // 명예의 전당
        List<int> kScore = new List<int>();
        
        for(int i = 0; i < length; i++)
        {
            // 전당 등록
            kScore.Add(score[i]);
            // 정렬
            kScore.Sort();
            // 전당 정원초과 시 제거(맨 앞이 제일 작은 수)
            if(kScore.Count > k)
                kScore.RemoveAt(0);
            // 갱신 후 꼴찌 등록
            answer[i] = kScore[0];
        }
        return answer;
    }
}
```
### 2. `PriorityQueue` 활용
``` C#
using System;
using System.Collections.Generic;

public class Solution {
    public int[] solution(int k, int[] score) {
        int length = score.Length;
        int[] answer = new int[length];
        
        // <요소의 타입, 우선순위의 타입>
        PriorityQueue<int, int> kScore = new PriorityQueue<int, int>();
        
        for(int i = 0; i < score.Length; i++) 
        {
            // 전당에 등록 (값과 우선순위를 동일하게 줌)
            kScore.Enqueue(score[i], score[i]);
            
            // 전당 정원초과 시 제거(맨 앞이 제일 작은 수)
            if(kScore.Count > k) 
                kScore.Dequeue();
            
            // 현재 전당의 최하위 점수(루트 노드)를 꺼내지 않고 보고(Peek) 기록
            answer[i] = kScore.Peek();
        }
        
        return answer;
    }
}
```

## ⏱️ 복잡도
### 1. `List.Sort()` 활용
- 시간: O(N × k log k) - 매 점수마다 정렬
- 공간: O(k) - `kScore` 리스트
### 2. `PriorityQueue` 활용
- 시간: O(N log k) - 각 연산이 O(log k)
- 공간: O(k) - `kScore` 우선순위큐
