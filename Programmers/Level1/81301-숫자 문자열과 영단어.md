# [Lv1] 숫자 문자열과 영단어

> **유형:** `#문자열` `#구현`
> **링크:** [81301](https://school.programmers.co.kr/learn/courses/30/lessons/81301)

## 📝 문제 요약
네오와 프로도가 숫자놀이를 하고 있습니다. 
네오가 프로도에게 숫자를 건넬 때 일부 자릿수를 영단어로 바꾼 카드를 건네주면 프로도는 원래 숫자를 찾는 게임입니다.

다음은 숫자의 일부 자릿수를 영단어로 바꾸는 예시입니다.

- 1478 → "one4seveneight"
- 234567 → "23four5six7"
- 10203 → "1zerotwozero3"

이렇게 숫자의 일부 자릿수가 영단어로 바뀌어졌거나, 혹은 바뀌지 않고 그대로인 문자열 s가 매개변수로 주어집니다. `s`가 의미하는 원래 숫자를 return 하도록 solution 함수를 완성해주세요.

## 💡 접근/풀이 방식
- 단순히 읽는 내용에 따라 숫자를 바꾸는 것이기에 0부터 시작하는 배열형식의 인덱스에 맞춰 바꿨다.

## 💻 풀이 코드 (C#)

```C#
using System;

public class Solution {
    public int solution(string s) {
        string[] numString = new string[] {"zero","one","two","three","four","five","six","seven","eight","nine"};
        for(int i = 0; i < numString.Length; i++)
        {
            s = s.Replace(numString[i], i.ToString());
        }
        int answer = int.Parse(s);
        return answer;
    }
}
```

## ⏱️ 복잡도
- 시간: O(N) - `Replace`를 10회 호출 (10은 상수)
- 공간: O(N) - `Replace`가 새 문자열을 반환
