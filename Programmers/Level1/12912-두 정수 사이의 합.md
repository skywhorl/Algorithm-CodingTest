# [Lv1] 두 정수 사이의 합

> **유형:** `#Math`, `#등차수열의합`
> **링크:** [12912](https://school.programmers.co.kr/learn/courses/30/lessons/12912)

## 📝 문제 요약
두 정수 `a`, `b`가 주어졌을 때 `a`와 `b` 사이에 속한 모든 정수의 합을 리턴하는 함수, solution을 완성하세요.
예를 들어 a = 3, b = 5인 경우, 3 + 4 + 5 = 12이므로 12를 리턴합니다.

## 💡 접근/풀이 방식
### 1. 반복문 풀이
- 두 수 사이의 범위를 반복문으로 돌리면 되지만, 누구의 수가 큰 수인지 알 수 없기에 `Math.Max()`, `Math.Min()`을 이용하여 최대/최소를 찾을 수 있다.
### 2. 등차수열의 합
- `(첫 항 + 마지막 항) * 항의 개수 / 2`의 공식을 통해 단번에 구할 수 있다.

## 💻 풀이 코드 (C#)
### 1. 반복문 풀이
```C#
using System;

public class Solution {
    public long solution(int a, int b) {
        long answer = 0;
        int min = Math.Min(a, b);
        int max = Math.Max(a, b);
        
        for(int i = min; i <= max; i++)
            answer += i;
        
        return answer;
    }
}
```
### 2. 등차수열의 합
```C#
using System;

public class Solution {
    public long solution(int a, int b) {
        // 문제 내 int 오버플로우로 long으로 캐스팅
        long min = Math.Min(a, b);
        long max = Math.Max(a, b);
        
        // 항의 개수: (max - min + 1)
        // 등차수열의 합: (항의 개수) * (첫 항 + 마지막 항) / 2
        return (max - min + 1) * (min + max) / 2;
    }
}
```
