# [Lv1] 중요한 단어를 스포 방지

> **유형:** `#해시` `#문자열` `#구현`
> **링크:** [468370](https://school.programmers.co.kr/learn/courses/30/lessons/468370)

## 📝 문제 요약
카카오톡은 메시지의 일부를 가려두었다가, 클릭했을 때만 공개되는 스포 방지 기능을 제공합니다. 이 기능을 활용하면 중요한 정보를 가리고 보낼 수 있습니다.

무지는 이 기능을 이용해 하나의 메시지 곳곳에 스포 방지 기능을 적용해 당신에게 보냈습니다. 
당신은 메시지 시작부터 왼쪽 → 오른쪽 순서로 스포 방지 구간을 하나씩 클릭해 공개되는 단어들 중, 중요한 단어가 몇 개인지 확인하려 합니다.

< 단어 및 중요한 단어 규칙 >

- 단어는 공백으로 구분되며, 알파벳 소문자와 숫자로만 구성된 연속된 문자열입니다.
- 단어를 구성하는 문자들의 인덱스 중 하나 이상이 스포 방지 구간에 포함될 경우, 해당 단어는 스포일러 방지 단어로 간주합니다. 즉, 단어 내 일부 문자에만 스포일러 방지 기능이 적용되더라도, 해당 단어 전체를 스포일러 방지 단어로 간주합니다.
- 한 단어가 여러 개의 스포 방지 구간에 걸쳐 있을 수 있으며, 하나의 스포 방지 구간에 여러 단어가 포함될 수 있습니다.
- 스포 방지 구간을 클릭해 단어의 모든 문자가 공개되었을 때, 그 단어가 아래 조건을 모두 만족하면 중요한 단어입니다.
  1. 스포 방지 단어여야 합니다.
  2. 메시지의 스포 방지 구간이 아닌 구간(= 어떤 스포 방지 구간에도 속하지 않는 모든 구간: 각 구간의 앞·사이·뒤 포함)에 등장한 적이 없어야 합니다.
  3. 이전에 공개된 스포 방지 단어와 중복되지 않아야 합니다.
  4. 여러 단어가 동시에 공개된 경우, 왼쪽부터 순서대로 하나씩 중요한 단어인지 판단합니다.
무지가 당신에게 보내온 메시지를 나타내는 문자열 `message`와 스포 방지가 적용된 구간을 나타내는 2차원 정수 배열 `spoiler_ranges`가 매개변수로 주어질 때, 스포 방지 단어 중 중요한 단어의 수를 return 하도록 solution 함수를 완성해 주세요.

## 💡 접근/풀이 방식
- `message`를 읽을 때 어느 구간(특정 스포일러 구간인지 확인)을 읽는지도 중요하기에 가독성을 위해 단어의 정보와 길이를 저장할 수 있는 클래스 형식을 만들었다.
- 스포일러 구간에 들어온 단어와 스포일러 구간에 들어오지 않은 단어 모두의 정보가 필요하기에 중복을 미리 제거한 HashSet이 필요했다.
- 이후 Collections.Contains()를 통해 단어들을 검색해 중요한 단어인지 아닌지 판별할 수 있다. 

## 💻 풀이 코드 (C#)

```C#
using System;
using System.Collections.Generic;

public class Solution {
    public int solution(string message, int[,] spoiler_ranges) {
        int answer = 0;
        int rangeCount = spoiler_ranges.GetLength(0);
        
        // 해당 단어의 위치를 저장할 리스트
        List<WordInfo> words = new List<WordInfo>();
        string[] split = message.Split(' ');
        // 현재 읽는 구간(위치)
        int currentIdx = 0;
        
        foreach (string s in split) 
        {
            words.Add(new WordInfo { Text = s, Start = currentIdx, End = currentIdx + s.Length - 1 });
            // 해당 단어 길어 + 띄어쓰기 1
            currentIdx += s.Length + 1; 
        }
        
        // 스포일러 구간에 포함 안 되는 단어들(일반 단어)
        HashSet<string> nonSpoilerWords = new HashSet<string>();

        foreach (WordInfo word in words) 
        {
            // 스포일러 단어인지 체크
            bool isSpoiler = false;
            
            for (int i = 0; i < rangeCount; i++) 
            {
                // 스포일러 구간에 들어왔으면
                if (!(word.End < spoiler_ranges[i, 0] || word.Start > spoiler_ranges[i, 1])) 
                {
                    isSpoiler = true;
                    break;
                }
            }
            // 스포일러 구간에 들어온 단어가 아니면 저장
            if (!isSpoiler) nonSpoilerWords.Add(word.Text);
        }
        
        // 중요한 단어 내용들
        HashSet<string> discoveredImportant = new HashSet<string>();
        for (int i = 0; i < rangeCount; i++) 
        {
            foreach (WordInfo info in words) 
            { 
                // 스포일러 구간내에 있는 단어인지
                if (!(info.End < spoiler_ranges[i, 0] || info.Start > spoiler_ranges[i, 1])) 
                {
                    // 이전에 이미 발견된 단어가 아닌지 확인
                    if (!nonSpoilerWords.Contains(info.Text) && !discoveredImportant.Contains(info.Text)) 
                    {
                        answer++;
                        discoveredImportant.Add(info.Text);
                    }
                }
            }
        }
        return answer;
    }

    // 단어와 단어의 위치 정보
    public class WordInfo {
        public string Text;
        public int Start;
        public int End;
    }
}
```

## ⏱️ 복잡도
- 시간: O(W × R) - 각 단어(W)마다 모든 구간(R) 검사
- 공간: O(W) - `words` 리스트와 HashSet들
