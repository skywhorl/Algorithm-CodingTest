# 소수 만들기
### [Lv.1 - 12977](https://school.programmers.co.kr/learn/courses/30/lessons/12977)

## 문제
주어진 숫자 중 3개의 수를 더했을 때 소수가 되는 경우의 개수를 구하려고 합니다. 
숫자들이 들어있는 배열 `nums`가 매개변수로 주어질 때, `nums`에 있는 숫자들 중 서로 다른 3개를 골라 더했을 때 소수가 되는 경우의 개수를 return 하도록 solution 함수를 완성해주세요.

### 제한사항
`nums`에 들어있는 숫자의 개수는 3개 이상 50개 이하입니다.
`nums`의 각 원소는 1 이상 1,000 이하의 자연수이며, 중복된 숫자가 들어있지 않습니다.
## 풀이
- 제한사항에서 최소 3개의 수가 들어가기에 삼중 반복문에서 초기 조건을 3개로 맞췄다.
- 소수를 판별할 때 약수의 대칭성을 이용하여 `나머지 계산 시 수의 제곱근 < 판별하려는 소수`로 조건을 맞추면 검산을 덜하게 된다.

``` C#
using System;

class Solution
{
    public int solution(int[] nums)
    {
        int answer = 0;
        int length = nums.Length;

        for (int i = 0; i < length; i++) 
        {
            for (int j = i + 1; j < length; j++) 
            {
                for (int k = j + 1; k < length; k++) 
                {
                    int sum = nums[i] + nums[j] + nums[k];
                    
                    // 소수 판별
                    if (IsPrime(sum)) 
                        answer++;
                }
            }
        }

        return answer;
    }

    // 소수 판별
    private bool IsPrime(int n) {
        // 2미만은 판별 대상 아님
        if (n < 2) 
            return false;
        
        for (int i = 2; i * i <= n; i++) 
        {
            if (n % i == 0) 
                return false;
        }
        return true;
    }
}
```
