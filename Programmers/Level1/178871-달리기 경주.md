# [Lv1] 달리기 경주

> **유형:** `#해시` `#배열`
> **링크:** [178871](https://school.programmers.co.kr/learn/courses/30/lessons/178871)

## 📝 문제 요약
얀에서는 매년 달리기 경주가 열립니다. 해설진들은 선수들이 자기 바로 앞의 선수를 추월할 때 추월한 선수의 이름을 부릅니다. 
예를 들어 1등부터 3등까지 `"mumu"`, `"soe"`, `"poe"` 선수들이 순서대로 달리고 있을 때, 해설진이 `"soe"`선수를 불렀다면 2등인 `"soe"` 선수가 1등인 `"mumu"` 선수를 추월했다는 것입니다. 
즉 `"soe"` 선수가 1등, `"mumu"` 선수가 2등으로 바뀝니다.

선수들의 이름이 1등부터 현재 등수 순서대로 담긴 문자열 배열 `players`와 해설진이 부른 이름을 담은 문자열 배열 `callings`가 매개변수로 주어질 때, 경주가 끝났을 때 선수들의 이름을 1등부터 등수 순서대로 배열에 담아 return 하는 solution 함수를 완성해주세요.

## 💡 접근/풀이 방식
- 선수 이름과 순위를 동시에 다룰 수 있게 Dictionary를 활용했고 `rank[players[i]] = i;` 같이 (본인이 지정한) string 타입 자체로 값을 지정해 저장할 수 있다.

## 💻 풀이 코드 (C#)

```C#
using System;
using System.Collections.Generic;

public class Solution {
    public string[] solution(string[] players, string[] callings) {
        // 유연한 순위 교체를 위한 Dictionary
        Dictionary<string, int> rank = new Dictionary<string, int>();
        
        // 현재 선수들의 순위 저장
        for(int i = 0; i < players.Length; i++)
        {
            rank[players[i]] = i;
        }
        
        foreach(string call in callings)
        {
            // 추월한 등수
            int currentRank = rank[call];
            
            //추월 당하는 선수의 이름 및 등수(기존 앞 선수)
            int frontRank = currentRank - 1;
            string frontPlayer = players[frontRank];
            
            // 선수 명단에서의 순위 교체
            players[frontRank] = call;
            players[currentRank] = frontPlayer;
            
            // Dictionary에서의 순위 교체
            rank[call] = frontRank;
            rank[frontPlayer] = currentRank;
        }
        
        return players;
    }
}
```

## ⏱️ 복잡도
- 시간: O(P + C) - `players` 초기화 후 호출마다 Dictionary 연산은 O(1)
- 공간: O(P) - `rank` 딕셔너리
