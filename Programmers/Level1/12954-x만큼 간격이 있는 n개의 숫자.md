# [Lv1] x만큼 간격이 있는 n개의 숫자

> **유형:** `#배열` `#자료형`
> **링크:** [12954](https://school.programmers.co.kr/learn/courses/30/lessons/12954)

## 📝 문제 요약
함수 solution은 정수 `x`와 자연수 `n`을 입력 받아, `x`부터 시작해 `x`씩 증가하는 숫자를 `n`개 지니는 리스트를 리턴해야 합니다. 
### 제한 조건
`x`는 -10000000 이상, 10000000 이하인 정수입니다.
`n`은 1000 이하인 자연수입니다.

## 💡 접근/풀이 방식
- `x`를 통해 계산할 때 타입 변환에만 주의하면 문제 없다.

## 💻 풀이 코드 (C#)

```C#
public class Solution {
    public long[] solution(int x, int n) {
        long[] answer = new long[n];
        
        for(int i = 0; i < n; i++)
        {
            answer[i] = (long)(x) * (i + 1);
        }
        
        return answer;
    }
}
```

## ⏱️ 복잡도
- 시간: O(N) - `n`만큼 반복하여 배열 채우기
- 공간: O(N) - `answer` 배열
