# [Lv1] 3진법 뒤집기

> **유형:** `#문자열` `#수학`
> **링크:** [68935](https://school.programmers.co.kr/learn/courses/30/lessons/68935)

## 📝 문제 요약
자연수 `n`이 매개변수로 주어집니다. `n`을 3진법 상에서 앞뒤로 뒤집은 후, 이를 다시 10진법으로 표현한 수를 return 하도록 solution 함수를 완성해주세요.

## 💡 접근/풀이 방식
- string 타입을 유동적으로 변경할 땐 메모리 효율이 좋은 StringBuilder를 채택했다.
- 10진법의 수를 3으로 나누고 그 나머지를 자릿수 별로 표현하면 3진수로 표현이 된다.
- 이후 3진법의 자릿수마다 거듭제곱에 맞게 3을 곱해주면 다시 10진수으로 표현이 된다.

## 💻 풀이 코드 (C#)

```C#
using System;
using System.Text;

public class Solution {
    public int solution(int n) {
        int answer = 0;
        StringBuilder sb = new StringBuilder();
        // 3진법 변환
        while(n != 0)
        {
            sb.Append(n%3);
            n /= 3;
        }
        
        // 변환한 내용 string 타입으로 저장
        string three = sb.ToString();
        // 3진법 자릿수(시작은 0승)
        int num = 1;

        for (int i = three.Length - 1; i >= 0; i--)
        {
            answer += (int)(three[i] - '0') * num;
            // 자릿수에 맞는 거듭제곱
            num *= 3;
        }

        return answer;
    }
}
```

## ⏱️ 복잡도
- 시간: O(log N) - 매 반복마다 `n /= 3`
- 공간: O(log N) - `sb`가 자릿수 길이만큼
