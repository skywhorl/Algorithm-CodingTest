# [Lv1] 문자열 내림차순으로 배치하기

> **유형:** `#문자열처리`, `#정렬`, `#ASCII`, `#Linq`
> **링크:** [12917](https://school.programmers.co.kr/learn/courses/30/lessons/12917)

## 📝 문제 요약
문자열 `s`에 나타나는 문자를 큰것부터 작은 순으로 정렬해 새로운 문자열을 리턴하는 함수, solution을 완성해주세요.

## 💡 접근/풀이 방식
### 1. 기본 배열 정렬
- 알파벳 문자는 아스키코드 순으론 대문자, 소문자 순이기에 `char[]`로 바꾸어 `Array.Sort()`로 정렬, `Array.Reverse()`로 역순 배치해주면 된다.
- 참고로, `char[]`을 다시 `strirg` 타입으로 변경할 때 `string.Concat()`으로 붙여도 되지만, `new string()`이 더 효율적이고 빠르다.
### 2. Linq 활용
- 바로 역순으로 배치해주는 `IEnumerable.OrderByDescending()`을 이용해주면 된다.

## 💻 풀이 코드 (C#)
### 1. 기본 배열 정렬
```C#
using System;

public class Solution {
    public string solution(string s) {
        char[] ca = s.ToCharArray();
        Array.Sort(ca);
        Array.Reverse(ca);
        return new string(ca);
    }
}
```
### 2. Linq 활용
```C#
using System.Linq;

public class Solution {
    public string solution(string s) {
        return new string(s.OrderByDescending(c => c).ToArray());
    }
}
```
