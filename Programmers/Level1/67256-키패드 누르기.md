# [Lv1] 키패드 누르기

> **유형:** `#배열` `#구현`
> **링크:** [67256](https://school.programmers.co.kr/learn/courses/30/lessons/67256)

## 📝 문제 요약
전화 키패드에서 왼손과 오른손의 엄지손가락만을 이용해서 숫자만을 입력하려고 합니다.
맨 처음 왼손 엄지손가락은 * 키패드에 오른손 엄지손가락은 # 키패드 위치에서 시작하며, 엄지손가락을 사용하는 규칙은 다음과 같습니다(이미지는 문제 링크 참고).

1. 엄지손가락은 상하좌우 4가지 방향으로만 이동할 수 있으며 키패드 이동 한 칸은 거리로 1에 해당합니다.
2. 왼쪽 열의 3개의 숫자 1, 4, 7을 입력할 때는 왼손 엄지손가락을 사용합니다.
3. 오른쪽 열의 3개의 숫자 3, 6, 9를 입력할 때는 오른손 엄지손가락을 사용합니다.
4. 가운데 열의 4개의 숫자 2, 5, 8, 0을 입력할 때는 두 엄지손가락의 현재 키패드의 위치에서 더 가까운 엄지손가락을 사용합니다.
만약 두 엄지손가락의 거리가 같다면, 오른손잡이는 오른손 엄지손가락, 왼손잡이는 왼손 엄지손가락을 사용합니다.

순서대로 누를 번호가 담긴 배열 `numbers`, 왼손잡이인지 오른손잡이인 지를 나타내는 문자열 `hand`가 매개변수로 주어질 때, 각 번호를 누른 엄지손가락이 왼손인 지 오른손인 지를 나타내는 연속된 문자열 형태로 return 하도록 solution 함수를 완성해주세요.

### 제한사항
`numbers` 배열의 크기는 1 이상 1,000 이하입니다.
`numbers` 배열 원소의 값은 0 이상 9 이하인 정수입니다.
`hand`는 `"left"` 또는 `"right"` 입니다.
`"left"`는 왼손잡이, `"right"`는 오른손잡이를 의미합니다.
왼손 엄지손가락을 사용한 경우는 `L`, 오른손 엄지손가락을 사용한 경우는 `R`을 순서대로 이어붙여 문자열 형태로 return 해주세요.

## 💡 접근/풀이 방식
- 각 키패드를 좌표 형식으로 지정해 손의 위치를 옮길 때마다 좌표로 저장했다.
- 가장 가까운 손은 설정해 둔 좌표를 이용해 거리를 계산하도록 했다.

## 💻 풀이 코드 (Java)

```Java
import java.util.*;

class Solution {
    public String solution(int[] numbers, String hand) {
        StringBuilder answer = new StringBuilder();
        
        // 왼손(*) / 오른손(#) 시작 위치, 키패드 1이 {0, 0}
        int[] leftHand = {3, 0};
        int[] rightHand = {3, 2};
        
        for(int num : numbers)
        {
            // 왼손 컨트롤
            if (num == 1 || num == 4 || num == 7) {
                answer.append("L");
                leftHand = GetPos(num);
            }
            // 오른손 컨트롤
            else if (num == 3 || num == 6 || num == 9) {
                answer.append("R");
                rightHand = GetPos(num);
            }
            else
            {
                // 해당 위치를 좌표로 변환
                int[] target = GetPos(num);
                
                // 각각 손에서 목표 지점까지의 거리 계산
                int leftLen = Math.abs(leftHand[0] - target[0]) + Math.abs(leftHand[1] - target[1]);
                int rightLen = Math.abs(rightHand[0] - target[0]) + Math.abs(rightHand[1] - target[1]);
                
                // 거리 비교에 따른 결과 입력
                if (leftLen < rightLen) 
                {
                    answer.append("L");
                    leftHand = target;
                } 
                else if (rightLen < leftLen) 
                {
                    answer.append("R");
                    rightHand = target;
                } 
                else 
                {
                    // 거리가 동일하면 hand에 따라 변경 
                    if (hand.equals("left")) {
                        answer.append("L");
                        leftHand = target;
                    } else {
                        answer.append("R");
                        rightHand = target;
                    }
                }
            }
        }
        return answer.toString();
    }
    
    // 키패드의 좌표 반환 함수
    private int[] GetPos(int num){
        // 키패드 0 위치는 따로 계산
        if(num == 0){return new int[] {3, 1};}
        
        return new int[]{(num-1) / 3, (num-1) % 3};
    }
}
```

## ⏱️ 복잡도
- 시간: O(N) - `numbers` 한 번 순회
- 공간: O(N) - `answer` StringBuilder
