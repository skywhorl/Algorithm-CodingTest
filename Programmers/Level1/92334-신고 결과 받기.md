# 신고 결과 받기
### [Lv.1 - 92334](https://school.programmers.co.kr/learn/courses/30/lessons/92334)

## 문제
신입사원 무지는 게시판 불량 이용자를 신고하고 처리 결과를 메일로 발송하는 시스템을 개발하려 합니다. 무지가 개발하려는 시스템은 다음과 같습니다.

- 각 유저는 한 번에 한 명의 유저를 신고할 수 있습니다.
  - 신고 횟수에 제한은 없습니다. 서로 다른 유저를 계속해서 신고할 수 있습니다.
  - 한 유저를 여러 번 신고할 수도 있지만, 동일한 유저에 대한 신고 횟수는 1회로 처리됩니다.
- k번 이상 신고된 유저는 게시판 이용이 정지되며, 해당 유저를 신고한 모든 유저에게 정지 사실을 메일로 발송합니다.
  - 유저가 신고한 모든 내용을 취합하여 마지막에 한꺼번에 게시판 이용 정지를 시키면서 정지 메일을 발송합니다.

이용자의 ID가 담긴 문자열 배열 `id_list`, 각 이용자가 신고한 이용자의 ID 정보가 담긴 문자열 배열 `report`, 정지 기준이 되는 신고 횟수 `k`가 매개변수로 주어질 때,
각 유저별로 처리 결과 메일을 받은 횟수를 배열에 담아 return 하도록 solution 함수를 완성해주세요.
## 풀이
- 신고와 신고 건수를 등록할 Dictionary의 형태에서 중복 신고 내역은 1건으로 처리하기에 중복을 자동으로 제거해주는 HashSet을 이용했다.

``` C#
using System;
using System.Collections.Generic;

public class Solution {
    public int[] solution(string[] id_list, string[] report, int k) {
        int[] answer = new int[id_list.Length];
        
        // 중복 제거 리스트
        HashSet<string> finalReport = new HashSet<string>(report);
        // [피신고자 : 신고자 목록]
        Dictionary<string, HashSet<string>> reportFile = new Dictionary<string, HashSet<string>>();
        
        // 유저 등록
        foreach(string id in id_list)
        {
            reportFile[id] = new HashSet<string>();
        }
        
        // report의 신고 내역을 저장
        foreach(string list in finalReport)
        {
            // report는 띄어쓰기로 id가 분류되어 있기에 분리
            string[] id = list.Split(' ');
            // [0 : 신고자, 1 : 피신고자]
            reportFile[id[1]].Add(id[0]);
        }
        
        for(int i = 0; i < id_list.Length; i++)
        {
            // 신고 당한 유저를 검색할 변수
            string user = id_list[i];
            // 신고 당한 카운트
            int count = 0;
            
            // 검색한 값을 가져올 것이기에 KeyValuePair 사용
            foreach(KeyValuePair<string, HashSet<string>> search in reportFile)
            {
                // 신고 리스트에 있음 && k번 이상 신고 당함
                if(search.Value.Contains(user) && search.Value.Count >= k)
                {
                    answer[i]++;
                }
            }
        }

        return answer;
    }
}
```
