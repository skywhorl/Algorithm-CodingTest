# [Lv1] 서울에서 김서방 찾기

> **유형:** `#문자열 처리` `#Array`
> **링크:** [12919](https://school.programmers.co.kr/learn/courses/30/lessons/12919)

## 📝 문제 요약
String형 배열 `seoul`의 element중 "Kim"의 위치 `x`를 찾아, `"김서방은 x에 있다"`는 String을 반환하는 함수, solution을 완성하세요. 
`seoul`에 `"Kim"`은 오직 한 번만 나타나며 잘못된 값이 입력되는 경우는 없습니다.

## 💡 접근/풀이 방식
### 1. 반복문 직접 탐색
- string에서 특정 단어를 찾으려면 `string.Contains(element)`를 통해 찾을 수 있지만 연산자 `==`가 훨씬 안전하고 속도도 빠르다.
### 2. 배열 기능 활용
- `Array.IndexOf()`를 통해 해당 요소를 바로 찾을 수 있다.
- 참고로, 위와 같이 찾아주는 코드로 `Array.FindIndex(seoul, i => i == "Kim");`도 있다.

## 💻 풀이 코드 (C#)
### 1. 반복문 직접 탐색
```C#
public class Solution {
    public string solution(string[] seoul) {
   
        for(int i = 0; i < seoul.Length; i++)
        {
            if(seoul[i] == "Kim")
                return string.Format("김서방은 {0}에 있다",i);
        }
        
        return "";
    }
}
```
### 2. 배열 기능 활용
```C#
using System;

public class Solution {
    public string solution(string[] seoul) {
        int index = Array.IndexOf(seoul, "Kim");
        return $"김서방은 {index}에 있다";
    }
}
```
