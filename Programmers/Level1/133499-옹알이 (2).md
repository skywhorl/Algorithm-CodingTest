# [Lv1] 옹알이 (2)

> **유형:** `#문자열` `#구현`
> **링크:** [133499](https://school.programmers.co.kr/learn/courses/30/lessons/133499)

## 📝 문제 요약
머쓱이는 태어난 지 11개월 된 조카를 돌보고 있습니다. 조카는 아직 `"aya", "ye", "woo", "ma"` 네 가지 발음과 네 가지 발음을 조합해서 만들 수 있는 발음밖에 하지 못하고 연속해서 같은 발음을 하는 것을 어려워합니다. 
문자열 배열 `babbling`이 매개변수로 주어질 때, 머쓱이의 조카가 발음할 수 있는 단어의 개수를 return하도록 solution 함수를 완성해주세요.

## 💡 접근/풀이 방식
- 문제에서는 안 적혀 있지만, 발음 가능한 단어가 연속해서 오는 경우는 제외하기에 `string.Contains()`에서 단어를 연속해 붙여 중복의 경우를 고려했다.
- `string.Replace()`에서 `""`이 아닌 `" "`으로 띄어쓰기 대체를 한 것은, 바로 없다고 표시하면 지워진 자리가 합쳐져 원치 않는 단어들도 지워질 수 있기에 안전하게 제거하는 방식을 택했다.

## 💻 풀이 코드 (C#)

```C#
using System;

public class Solution {
    public int solution(string[] babbling) {
        int answer = 0;
        string[] canSay = {"aya", "ye", "woo", "ma"};
        
        for(int i = 0; i < babbling.Length; i++)
        {
            // 발음 가능한 단어들인지
            bool canTalk = true;
            
             // 연속된 단어 체크
            foreach(string say in canSay)
            {
                if(babbling[i].Contains(say + say))
                {
                    canTalk = false;
                    break;
                }
            }
            // 연속된 단어가 존재하면 다음으로 넘어가기
            if(!canTalk) continue;
            
            
            foreach(string say in canSay)
            {
                // 발음 가능한 단어는 공백으로 대체하기
                babbling[i] = babbling[i].Replace(say, " ");
            }
            // 길이를 비교하여 카운트
            if(babbling[i].Trim().Length == 0) answer++;
        }
 
        return answer;
    }
}
```

## ⏱️ 복잡도
- 시간: O(N × L) - N은 `babbling` 길이, L은 각 문자열 길이 (`Contains`/`Replace`)
- 공간: O(L) - `Replace` 호출이 새 문자열 생성
