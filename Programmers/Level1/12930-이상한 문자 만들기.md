# [Lv1] 이상한 문자 만들기

> **유형:** `#문자열`
> **링크:** [12930](https://school.programmers.co.kr/learn/courses/30/lessons/12930)

## 📝 문제 요약
문자열 `s`는 한 개 이상의 단어로 구성되어 있습니다. 각 단어는 하나 이상의 공백문자로 구분되어 있습니다. 
각 단어의 짝수번째 알파벳은 대문자로, 홀수번째 알파벳은 소문자로 바꾼 문자열을 리턴하는 함수, solution을 완성하세요.

## 💡 접근/풀이 방식
- 공백이 단순히 하나로 단어를 구분했다면 `string.Split()`으로 쉽게 바꾸면 됐겠지만, 공백이 여러 개인 경우가 존재하기에 `index`라는 변수를 따로 생성해 공백에 따라 인덱스가 조정되도록 설정했다.
- 코드에서는 일일이 아스키코드 연산(32)으로 대소문자를 계산했지만 `string.ToUpper()`, `string.ToLower()`로 쉽게 바꿀 수 있다.

## 💻 풀이 코드 (C#)

```C#
using System;

public class Solution {
    public string solution(string s) {
        string answer = "";
        // 띄어쓰기에 따라 index 초기화
        int index = 0;
        
        foreach(char c in s)
        {
            // 공백이면 index 초기화
            if(c == ' ')
            {
                answer += c;
                index = 0;
                continue;
            }
            
            // 짝수-대문자
            if(index%2 == 0)
                answer += ChangeLetter(c, -32);
            // 홀수-소문자
            else
                answer += ChangeLetter(c, 32);
            index++;
        }
        
        return answer;
    }
    
    // 대소문자 변경
    private char ChangeLetter(char c, int cal){
        // 연산 시 알파벳 범위 안에 있을 때만 변환
        if(c + cal <= 122 && c + cal >= 65)
            return (char)(c + cal);
        return c;
    }
}
```

## ⏱️ 복잡도
- 시간: O(N) - `s` 한 번 순회 (문자열 누적 연결은 O(N²) 위험이 있어 StringBuilder 권장)
- 공간: O(N) - `answer` 문자열
