# [Lv1] 가운데 글자 가져오기

> **유형:** `#문자열` `#구현`
> **링크:** [12903](https://school.programmers.co.kr/learn/courses/30/lessons/12903)

## 📝 문제 요약
단어 `s`의 가운데 글자를 반환하는 함수, solution을 만들어 보세요. 단어의 길이가 짝수라면 가운데 두글자를 반환하면 됩니다.

## 💡 접근/풀이 방식
### 1. 인덱스 접근
- 문자열 길이의 몫을 이용해 가운데 인덱스를 찾고, 짝수/홀수 여부에 따라 삼항 연산자를 활용해 문자를 합쳐서 반환했다.
### 2. Substring 활용
- `Substring(시작 인덱스, 길이)`을 사용하여 자를 위치와 길이만 구하면 된다.

## 💻 풀이 코드 (C#)
### 1. 인덱스 접근
```C#
public class Solution {
    public string solution(string s) {
        string answer = s[s.Length/2].ToString();
        return s.Length%2 != 0 ? answer : s[s.Length/2-1] + answer;
    }
}
```
### 2. Substring 활용
```C#
public class Solution {
    public string solution(string s) {
        // (s.Length - 1) / 2 를 하면 짝/홀수 상관없이 정확한 시작 인덱스가 나옴
        int startIndex = (s.Length - 1) / 2;
        
        // 짝수면 2글자, 홀수면 1글자를 자름
        int length = s.Length % 2 == 0 ? 2 : 1;
        
        return s.Substring(startIndex, length);
    }
}
```

## ⏱️ 복잡도
### 1. 인덱스 접근
- 시간: O(1) - 인덱스 접근만 사용
- 공간: O(1)
### 2. Substring 활용
- 시간: O(N) - `Substring`이 새 문자열 생성
- 공간: O(N) - 새 문자열
