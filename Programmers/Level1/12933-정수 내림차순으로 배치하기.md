# [Lv1] 정수 내림차순으로 배치하기

> **유형:** `#배열` `#정렬`
> **링크:** [12933](https://school.programmers.co.kr/learn/courses/30/lessons/12933)

## 📝 문제 요약
함수 solution은 정수 `n`을 매개변수로 입력받습니다. `n`의 각 자릿수를 큰것부터 작은 순으로 정렬한 새로운 정수를 리턴해주세요. 예를들어 `n`이 `118372`면 `873211`을 리턴하면 됩니다.

## 💡 접근/풀이 방식
- Linq를 쓰지 않고도 `Array.Sort()`로 오름차순 정렬 후 역순으로 배치해주는 `Array.Reverse()`로 내림차순을 만들 수 있다.
- `new string(char[])`로 `char[]`을 바로 `string` 타입으로 만들 수 있다.
- 참고로, Linq를 사용하게 된다면 바로 역순배치인 `OrderByDescending()`을 사용해주면 된다.

## 💻 풀이 코드 (C#)

```C#
using System;

public class Solution {
    public long solution(long n) {
        char[] numArray = n.ToString().ToCharArray();
        
        // 내림차순 정렬
        Array.Sort(numArray);
        Array.Reverse(numArray);
        
        return long.Parse(new string(numArray));
    }
}
```

- 시간: O(D log D) - `Array.Sort`가 자릿수 D에 대해
- 공간: O(D) - `numArray` 배열
