# [Lv1] 바탕화면 정리

> **유형:** `#배열` `#구현`
> **링크:** [161990](https://school.programmers.co.kr/learn/courses/30/lessons/161990)

## 📝 문제 요약
컴퓨터 바탕화면은 각 칸이 정사각형인 격자판입니다. 이때 컴퓨터 바탕화면의 상태를 나타낸 문자열 배열 `wallpaper`가 주어집니다. 
파일들은 바탕화면의 격자칸에 위치하고 바탕화면의 격자점들은 바탕화면의 가장 왼쪽 위를 (0, 0)으로 시작해 (세로 좌표, 가로 좌표)로 표현합니다. 빈칸은 ".", 파일이 있는 칸은 "#"의 값을 가집니다. 
드래그를 하면 파일들을 선택할 수 있고, 선택된 파일들을 삭제할 수 있습니다.

머쓱이의 컴퓨터 바탕화면의 상태를 나타내는 문자열 배열 `wallpaper`가 매개변수로 주어질 때 바탕화면의 파일들을 한 번에 삭제하기 위해 최소한의 이동거리를 갖는 드래그의 시작점과 
끝점을 담은 정수 배열을 return하는 solution 함수를 작성해 주세요. 드래그의 시작점이 (`lux`, `luy`), 끝점이 (`rdx`, `rdy`)라면 정수 배열 [`lux`, `luy`, `rdx`, `rdy`]를 return하면 됩니다.

## 💡 접근/풀이 방식
- 제한사항(링크 참고)에 `wallpaper` 길이가 최대 50이기에 `maxValue`로 값을 크게 잡지 않았다.
- 최소한의 범위를 찾아야 하기에 화면 영역보다 1 크거나 작은 범위를 시작으로 갱신하도록 설정했다.

## 💻 풀이 코드 (C#)

```C#
using System;

public class Solution {
    public int[] solution(string[] wallpaper) {       
        // 각 좌표 범위에서의 주어진 조건 최대/최소치(초깃값)
        int lux = 51;
        int luy = 51;
        int rdx = -1;
        int rdy = -1;
        
        for(int r = 0; r < wallpaper.Length; r++)
        {
            for(int c = 0; c < wallpaper[r].Length; c++)
            {
                // 파일 발견
                if(wallpaper[r][c] == '#')
                {
                    // 범위 안에 들어가면 갱신
                    if (r < lux) lux = r;
                    if (c < luy) luy = c;
                    if (r > rdx) rdx = r;
                    if (c > rdy) rdy = c;
                }
            }
        }
        
        return new int[]{ lux, luy, rdx + 1, rdy + 1 };
    }
}
```

## ⏱️ 복잡도
- 시간: O(R × C) - 2차원 격자 전체 스캔
- 공간: O(1)
