# [Lv1] 푸드 파이트 대회

> **유형:** `#문자열` `#배열`
> **링크:** [134240](https://school.programmers.co.kr/learn/courses/30/lessons/134240)

## 📝 문제 요약
음식의 양이 담긴 배열 `food`가 주어질 때, 대회를 위해 왼쪽 선수의 음식 배치와 오른쪽 선수의 음식 배치를 대칭으로 만들고, 한가운데에 물(`0`)을 배치한 문자열을 반환하세요.

## 💡 접근/풀이 방식
- 각 음식의 개수를 2로 나눈 몫만큼만 취해서 왼쪽 선수의 음식 배치(문자열)를 먼저 완성한다.
- string이 계속해서 수정될 경우 StringBuilder가 메모리 효율에 좋다.
- 이후 `Array.Reverse()`를 활용해 왼쪽 배치를 뒤집어 오른쪽 선수의 배치를 만든다.
- `왼쪽 배치 + "0" + 오른쪽 배치` 순서로 합친다.

## 💻 풀이 코드 (C#)

```C#
using System;
using System.Text;

public class Solution {
    public string solution(int[] food) {
        StringBuilder left = new StringBuilder();
        
        // 왼쪽 선수의 음식 배치
        for(int i = 1; i < food.Length; i++) {
            // 둘이 똑같이 나눠 먹을 수 있는 몫
            int count = food[i] / 2; 
            
            // 몫이 0보다 크면 개수만큼 번호(i)를 추가
            for(int j = 0; j < count; j++) {
                left.Append(i);
            }
        }
        
        string leftStr = left.ToString();
        
        // 왼쪽 내용 복사
        char[] rightArr = leftStr.ToCharArray();
        // 원본 뒤집기
        Array.Reverse(rightArr); 
        string rightStr = new string(rightArr);
        
        return leftStr + "0" + rightStr;
    }
}
```

## ⏱️ 복잡도
- 시간: O(F + L) - F는 `food` 길이, L은 왼쪽 문자열 누적 길이
- 공간: O(L) - `left` StringBuilder와 결과 문자열
