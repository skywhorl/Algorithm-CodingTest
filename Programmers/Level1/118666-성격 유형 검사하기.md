# [Lv1] 성격 유형 검사하기

> **유형:** `#Dictionary` `#Implementation`
> **링크:** [118666](https://school.programmers.co.kr/learn/courses/30/lessons/118666)

## 📝 문제 요약
질문마다 판단하는 지표를 담은 1차원 문자열 배열 `survey`와 검사자가 각 질문마다 선택한 선택지를 담은 1차원 정수 배열 `choices`가 매개변수로 주어집니다. 
이때, 검사자의 성격 유형 검사 결과를 지표 번호 순서대로 return 하도록 solution 함수를 완성해주세요.

## 💡 접근/풀이 방식
- 성격에 따라 점수를 부여해 비교해야 하므로 [Key: 성격], [Value: 점수] 형식의 Dictionary를 구현했다.

## 💻 풀이 코드 (C#)

```C#
using System;
using System.Collections.Generic;

public class Solution {
    public string solution(string[] survey, int[] choices) {
        string answer = "";
        // 질문에 따른 성격과 점수를 저장
        Dictionary<char, int> result = new Dictionary<char, int>();
        // 성격 유형
        char[] type = {'R', 'T', 'C', 'F', 'J', 'M', 'A', 'N'};
        
        // Dictionary 점수 초기화
        foreach(char t in type)
        {
            result[t] = 0;
        }
        
        for(int i = 0; i < survey.Length; i++)
        {
            // 선택한 내용
            int choice = choices[i];
            // 앞 유형
            if(choice < 4)
            {
                result[survey[i][0]] += (4 - choice);
            }
            // 뒤 유형
            else if(choice > 4)
            {
                result[survey[i][1]] += (choice - 4);
            }
        }
        
        // 지표에 맞게 각각 비교
        answer += result['R'] >= result['T'] ? "R" : "T";
        answer += result['C'] >= result['F'] ? "C" : "F";
        answer += result['J'] >= result['M'] ? "J" : "M";
        answer += result['A'] >= result['N'] ? "A" : "N";
        
        
        return answer;
    }
}

```
