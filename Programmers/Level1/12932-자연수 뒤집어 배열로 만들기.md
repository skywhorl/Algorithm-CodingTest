# [Lv1] 자연수 뒤집어 배열로 만들기

> **유형:** `#문자열` `#수학`
> **링크:** [12932](https://school.programmers.co.kr/learn/courses/30/lessons/12932)

## 📝 문제 요약
자연수 `n`을 뒤집어 각 자리 숫자를 원소로 가지는 배열 형태로 리턴해주세요. 예를들어 `n`이 `12345`이면 `[5,4,3,2,1]`을 리턴합니다.

## 💡 접근/풀이 방식
### 1. 아스키코드 활용
- char에서 다시 int 타입으로 변경할 땐 아스키코드로 '0'을 빼주면 된다.
### 2. 나머지 연산
- 구한 숫자를 리스트에 담고, 원래 숫자는 10으로 나누어 자릿수를 줄여가는 방식을 반복한다.

## 💻 풀이 코드 (C#)
### 1. 아스키코드 활용
```C#
using System;

public class Solution {
    public int[] solution(long n) {
        char[] arr = n.ToString().ToCharArray();
        int[] answer = new int[arr.Length];
        // n 뒤집기
        Array.Reverse(arr);

        for(int i = 0; i < arr.Length; i++)
        {
            answer[i] = arr[i] - '0';
        }
        return answer;
    }
}
```
### 2. 나머지 연산
``` C#
using System.Collections.Generic;

public class Solution {
    public int[] solution(long n) {
        List<int> answer = new List<int>();
        
        while(n > 0) 
        {
            // 맨 끝자리 숫자를 추출 후 추가
            answer.Add((int)(n % 10)); 
            // 자릿수를 하나씩 줄이기
            n /= 10; 
        }
        
        return answer.ToArray();
    }
}
```

## ⏱️ 복잡도
### 1. 아스키코드 활용
- 시간: O(D) - `n`의 자릿수 D만큼 처리
- 공간: O(D) - `arr`/`answer` 배열
### 2. 나머지 연산
- 시간: O(log N) - 매 반복마다 `n /= 10`
- 공간: O(log N) - `answer` 리스트
