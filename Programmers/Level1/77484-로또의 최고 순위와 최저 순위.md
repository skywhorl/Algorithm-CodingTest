# [Lv1] 로또의 최고 순위와 최저 순위

> **유형:** `#배열` `#구현`
> **링크:** [77484](https://school.programmers.co.kr/learn/courses/30/lessons/77484)

## 📝 문제 요약
로또를 구매한 민우는 당첨 번호 발표일을 학수고대하고 있었습니다. 
하지만, 민우의 동생이 로또에 낙서를 하여, 일부 번호를 알아볼 수 없게 되었습니다. 
당첨 번호 발표 후, 민우는 자신이 구매했던 로또로 당첨이 가능했던 최고 순위와 최저 순위를 알아보고 싶어 졌습니다.
민우가 구매한 로또 번호를 담은 배열 `lottos`, 당첨 번호를 담은 배열 `win_nums`가 매개변수로 주어집니다. 
이때, 당첨 가능한 최고 순위와 최저 순위를 차례대로 배열에 담아서 return 하도록 solution 함수를 완성해주세요.
### 제한사항
- `lottos`는 길이 6인 정수 배열입니다.
- `lottos`의 모든 원소는 0 이상 45 이하인 정수입니다.
- 0은 알아볼 수 없는 숫자를 의미합니다.
- 0을 제외한 다른 숫자들은 `lottos`에 2개 이상 담겨있지 않습니다.
- `lottos`의 원소들은 정렬되어 있지 않을 수도 있습니다.
- `win_nums`은 길이 6인 정수 배열입니다.
- `win_nums`의 모든 원소는 1 이상 45 이하인 정수입니다.
- `win_nums`에는 같은 숫자가 2개 이상 담겨있지 않습니다.
- `win_nums`의 원소들은 정렬되어 있지 않을 수도 있습니다.
- 로또는 숫자 6개 전부 일치 시 1등부터, 1개 및 전부 일치하지 않으면 6등립니다.

## 💡 접근/풀이 방식
- 번호 일치를 확인할 때는 편의를 위해 Linq에 있는 `Array.Contains()`를 이용하였다.
- 번호 일치를 확인할 때 당첨의 경우를 고려해야 하기에 0으로 표기된 내용을 카운트하였다.

## 💻 풀이 코드 (C#)

```C#
using System;
using System.Linq;

public class Solution {
    public int[] solution(int[] lottos, int[] win_nums) {
        int correct = 0;
        int zero = 0;
        
        foreach(int num in lottos)
        {
            // 경우의 수를 고려해야 하기에 0을 따로 카운트
            if(num == 0)    
                zero++;
            else
            {
                // 번호 일치 확인
                if(win_nums.Contains(num)) 
                    correct++;
            }
        }
        
        return new int[] {Rank(correct + zero), Rank(correct)};
    }
    
    // 등수 매기기
    private int Rank(int checkCorrect) {
        if(checkCorrect == 6)       return 1;
        else if(checkCorrect == 5)  return 2;
        else if(checkCorrect == 4)  return 3;
        else if(checkCorrect == 3)  return 4;
        else if(checkCorrect == 2)  return 5;
        else                        return 6;
    }
}
```

## ⏱️ 복잡도
- 시간: O(1) - `lottos`/`win_nums` 길이가 6으로 고정
- 공간: O(1)
