# 최대공약수와 최소공배수
### [Lv.1 - 12940](https://school.programmers.co.kr/learn/courses/30/lessons/12940)

## 문제
두 수를 입력받아 두 수의 최대공약수와 최소공배수를 반환하는 함수, solution을 완성해 보세요. 
배열의 맨 앞에 최대공약수, 그다음 최소공배수를 넣어 반환하면 됩니다. 예를 들어 두 수 3, 12의 최대공약수는 3, 최소공배수는 12이므로 `solution(3, 12)`는 `[3, 12]`를 반환해야 합니다.
## 풀이(Euclidean Algorithm)
- 최대공약수는 유클리드 호제법을 통해 두 수를 계속해서 나머지 연산을 하여 구할 수 있다, 아래 코드처럼 큰 수와 작은 수 구별이 필요하다.
- 최소공배수는 두 수의 곱에서 최대공약수를 나누면 된다.

``` C#
public class Solution {
    public int[] solution(int n, int m) { 
        // 최대공약수
        int gcd = n > m ? GCD(m, n) : GCD(n, m);
        // 최소공배수 = 두 수의 곱 / 두 수의 최대공약수
        return new int[] {gcd, (n * m) / gcd};
    }
    
    // 최대공약수 구하기
    private int GCD(int small, int big) {
        // 유클리드 호제법(서로 나누기)
        while(big != 0)
        {
            // 나머지 연산
            int rest = small % big;
            small = big;
            big = rest;
        }
        return small;
    }
}
```
