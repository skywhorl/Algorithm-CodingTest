# [Lv1] 최대공약수와 최소공배수

> **유형:** `#수학` `#유클리드호제법`
> **링크:** [12940](https://school.programmers.co.kr/learn/courses/30/lessons/12940)

## 📝 문제 요약
두 수를 입력받아 두 수의 최대공약수와 최소공배수를 반환하는 함수, solution을 완성해 보세요. 
배열의 맨 앞에 최대공약수, 그다음 최소공배수를 넣어 반환하면 됩니다.

## 💡 접근/풀이 방식
- 최대공약수는 유클리드 호제법을 통해 두 수를 계속해서 나머지 연산을 하여 구할 수 있다.
- 참고로, 두 수의 크기를 비교할 필요 없이 나머지 연산할 때 자동으로 처리가 된다.
- 최소공배수는 두 수의 곱에서 최대공약수를 나누면 된다.

## 💻 풀이 코드 (C#)

```C#
public class Solution {
    public int[] solution(int n, int m) { 
        // 최대공약수
        int gcd = GCD(n, m);
        // 최소공배수 = 두 수의 곱 / 두 수의 최대공약수
        return new int[] {gcd, (n * m) / gcd};
    }
    
    // 최대공약수 구하기
    private int GCD(int a, int b) {
        // 유클리드 호제법(서로 나누기)
        while(b != 0)
        {
            // 나머지 연산
            int rest = a % b;
            a = b;
            b = rest;
        }
        return a;
    }
}
```

## ⏱️ 복잡도
- 시간: O(log min(N, M)) - 유클리드 호제법
- 공간: O(1)
