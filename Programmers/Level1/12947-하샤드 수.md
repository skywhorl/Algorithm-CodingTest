# [Lv1] 하샤드 수

> **유형:** `#수학` `#자릿수합` `#LINQ`
> **링크:** [12947](https://school.programmers.co.kr/learn/courses/30/lessons/12947)

## 📝 문제 요약
양의 정수 `x`가 하샤드 수이려면 `x`의 자릿수의 합으로 `x`가 나누어져야 합니다. 
자연수 `x`를 입력받아 `x`가 하샤드 수인지 아닌지 검사하는 함수, solution을 완성해주세요.

## 💡 접근/풀이 방식
### 1. 수학적 접근
- 주어진 수의 자릿수가 일정하기 않기에 10씩 나누어 자릿수끼리의 합을 구할 수 있다.
### 2. Linq 활용
- 숫자를 문자열로 변환 후, `Sum()` 메서드와 아스키코드(`- '0'`)를 활용할 수 있다.

## 💻 풀이 코드 (C#)
### 1. 수학적 접근
```C#
public class Solution {
    public bool solution(int x) {
        return x % GetDigit(x) == 0 ? true : false;
    }
    
    // 자릿수의 합 구하기
    private int GetDigit(int num)
    {
        int sum = 0;
        while(num > 0)
        {
            sum += num % 10;
            num /= 10;
        }
        return sum;
    }
}
```
### 2. Linq 활용
```C#
using System.Linq;

public class Solution {
    public bool solution(int x) {
        // x를 문자열로 바꾼 뒤 각 문자를 정수로 변환하여 합산
        return x % x.ToString().Sum(c => c - '0') == 0;
    }
}
```

## ⏱️ 복잡도
### 1. 수학적 접근
- 시간: O(log N) - 매 반복마다 `num /= 10`
- 공간: O(1)
### 2. Linq 활용
- 시간: O(log N) - 자릿수만큼 `Sum`
- 공간: O(log N) - `ToString` 결과 문자열
