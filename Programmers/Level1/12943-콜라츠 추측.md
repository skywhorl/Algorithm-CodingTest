# [Lv1] 콜라츠 추측

> **유형:** `#구현` `#시뮬레이션` `#자료형`

## 📝 문제 요약
주어진 수가 1이 될 때까지 다음 작업을 반복합니다.
1. 짝수라면 2로 나눕니다. 
2. 홀수라면 3을 곱하고 1을 더합니다. 

위 작업을 몇 번이나 반복해야 하는지 반환하는 함수를 작성해주세요. 
단, 주어진 수가 1이면 0을, 500번 반복할 때까지 1이 되지 않으면 -1을 반환합니다.

## 💡 접근/풀이 방식
- 단위가 커지기에 오버플로우 방지를 위한 `long` 타입으로 변수를 선언했다.
- 문제 조건처럼 작업을 최대 500번까지 반복하기에 반복문에 500을 최대로 선언했고 도중에 return 하도록 설정했다.

## 💻 풀이 코드 (C#)

``` C#
public class Solution {
    public int solution(int num) {
        long lNum = num;
        for (int i = 0; i < 500; i++)
        {
            if (lNum == 1) return i;
            lNum = lNum % 2 == 0 ? lNum / 2 : lNum * 3 + 1;                  
        }
        return -1;        
    }
}
```

## ⏱️ 복잡도
- 시간: O(1) - 최대 500회 고정 반복
- 공간: O(1)
