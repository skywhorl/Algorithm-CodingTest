# 콜라츠 추측
### [Lv.1 - 12943](https://school.programmers.co.kr/learn/courses/30/lessons/12943)

## 문제
937년 Collatz란 사람에 의해 제기된 이 추측은, 주어진 수가 1이 될 때까지 다음 작업을 반복하면, 모든 수를 1로 만들 수 있다는 추측입니다. 작업은 다음과 같습니다.

```
1-1. 입력된 수가 짝수라면 2로 나눕니다. 
1-2. 입력된 수가 홀수라면 3을 곱하고 1을 더합니다. 
2. 결과로 나온 수에 같은 작업을 1이 될 때까지 반복합니다.
```
예를 들어, 주어진 수가 6이라면 6 → 3 → 10 → 5 → 16 → 8 → 4 → 2 → 1 이 되어 총 8번 만에 1이 됩니다. 위 작업을 몇 번이나 반복해야 하는지 반환하는 함수, solution을 완성해 주세요. 
단, 주어진 수가 1인 경우에는 0을, 작업을 500번 반복할 때까지 1이 되지 않는다면 –1을 반환해 주세요.
## 풀이
- 문제에 주어진 조건대로만 차근히 맞추면 풀 수 있지만, 연산 도중 int 범위를 넘어가는 경우가 존재하기에 long 타입으로 변환하여 계산했다.

``` C#
public class Solution {
    public int solution(int num) {
        int answer = 0;
        // int 범위 너머로 계산이 되는 수가 존재함
        long bigNum = num;
        
        while(bigNum != 1)
        {
            bigNum = bigNum%2 == 0 ? bigNum/2 : (bigNum*3)+1;
            answer++;
            if(answer >= 500)   return -1;
        }
        
        return answer;
    }
}
```
## 다른 풀이
- 500번 반복이라는 조건을 통해 for문으로도 구현할 수 있다.
``` C#
public class Solution {
    public int solution(int num) {
        long lNum = num;
        for (int i = 0; i < 500; i++)
        {
            if (lNum == 1) return i;
            lNum = lNum % 2 == 0 ? lNum / 2 : lNum * 3 + 1;                  
        }
        return -1;        
    }
}
```
