# [Lv1] 시저 암호

> **유형:** `#문자열` `#배열`
> **링크:** [12926](https://school.programmers.co.kr/learn/courses/30/lessons/12926)

## 📝 문제 요약
문자열 `s`와 거리 `n`을 입력받아 `s`를 `n`만큼 민 암호문을 만드는 함수, solution을 완성해 보세요.

## 💡 접근/풀이 방식
- z에서 a로 넘어가는 경우처럼 범위를 넘어서는 것을 확인하기 위해 알파벳 26자인 26을 나머지 연산하면 자동으로 넘길 수 있다.

## 💻 풀이 코드 (C#)

```C#
public class Solution {
    public string solution(string s, int n) {
        char[] ca = s.ToCharArray();
        
        for(int i = 0; i < ca.Length; i++)
        {
            // 공백이면 넘기기
            if(ca[i] == ' ') continue;
            
            // 대문자인 경우
            if(ca[i] >= 'A' && ca[i] <= 'Z') {
                ca[i] = (char)((ca[i] - 'A' + n) % 26 + 'A');
            }
            // 소문자인 경우
            else if(ca[i] >= 'a' && ca[i] <= 'z') {
                ca[i] = (char)((ca[i] - 'a' + n) % 26 + 'a');
            }
        }
        
        return new string(ca);
    }
}
```

## ⏱️ 복잡도
- 시간: O(N) - `ca` 한 번 순회
- 공간: O(N) - char 배열 생성
