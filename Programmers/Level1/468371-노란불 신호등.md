# 노란불 신호등
### [Lv.1 - 468371](https://school.programmers.co.kr/learn/courses/30/lessons/468371)

## 문제
어떤 도로에 차량 신호등이 n개 있습니다. 모든 신호등은 항상 초록불 → 노란불 → 빨간불 순서로 반복되며, 각 신호의 지속 시간은 신호등마다 다릅니다. 시간은 1초부터 시작하며, 각 신호등은 처음에는 초록불 상태로 시작합니다.

이 도로에서는 가끔 정전이 일어나는데, 모든 신호등이 모두 노란불이 되면 정전이 발생한다는 사실이 밝혀졌습니다.

신호등 `n`개의 신호 주기를 담은 2차원 정수 배열 `signals`가 매개변수로 주어집니다. 모든 신호등이 노란불이 되는 가장 빠른 시각(초)을 return 하도록 solution 함수를 완성해 주세요. 
만약 모든 신호등이 노란불이 되는 경우가 존재하지 않는다면 `-1`을 return 해주세요.
## 풀이
- 신호등을 검사할 때 어디까지 검사를 하기 위해 모든 신호등 검사 주기를 최소공배수로 설정했다.
- 계산의 편의를 위해 기존 시간에서 초록불 시간을 때 0초부터 노란불 시간까지의 변수를 구현했다(1을 뺀 이유는 배열 형태여서).

``` C#
using System;

public class Solution {
    public int solution(int[,] signals) {    
        // 모든 신호등의 최소공배수
        long lcm = 1;
        // 모든 신호등의 최소공배수 구하기
        for (int i = 0; i < signals.GetLength(0); i++) {
            // 신호등 주기
            int cycle = signals[i, 0] + signals[i, 1] + signals[i, 2];
            lcm = LCM(lcm, (long)cycle);
        }
        
        // 1초부터 최소공배수까지 검사
        for(int time = 1; time <= lcm; time++) {
            // 전부 노란불일 때 true
            bool isAllYellow = true;
            
            for (int i = 0; i < signals.GetLength(0); i++) {
                // 신호등 주기와 시간을 비교할 초록불과 노란불
                int g = signals[i, 0];
                int y = signals[i, 1];
                int totalCycle = g + y + signals[i, 2];

                // 노란불 상대적 시작점(계산 시 0부터 y까지)
                int yellowTime = (time - 1) - g;
                
                // 노란불 범위가 아니면 통과
                if (yellowTime < 0 || (yellowTime % totalCycle) >= y) {
                    isAllYellow = false;
                    break;
                }
            }
            // 전부 노란불
            if (isAllYellow) return time;
        }
        // 다 돌아도 없으면 -1
        return -1;
    }
    
    // 최대공약수(최소공배수 구하는 용도)
    private long GCD(long a, long b) {
        while(b != 0)
        {
            long temp = a % b;
            a = b;
            b = temp;
        }
        return a;
    }
    
    // 최소공배수
    private long LCM(long a, long b) {
        if (a == 0 || b == 0) return 0;
        return (a * b) / GCD(a, b);
    }
}
```
