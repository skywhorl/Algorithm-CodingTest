# [Lv1] 공원 산책

> **유형:** `#배열` `#시뮬레이션`
> **링크:** [172928](https://school.programmers.co.kr/learn/courses/30/lessons/172928)

## 📝 문제 요약
지나다니는 길을 'O', 장애물을 'X'로 나타낸 직사각형 격자 모양의 공원에서 로봇 강아지가 산책을 하려합니다. 산책은 로봇 강아지에 미리 입력된 명령에 따라 진행하며, 명령은 다음과 같은 형식으로 주어집니다.

["방향 거리", "방향 거리" … ]
예를 들어 "E 5"는 로봇 강아지가 현재 위치에서 동쪽으로 5칸 이동했다는 의미입니다. 로봇 강아지는 명령을 수행하기 전에 다음 두 가지를 먼저 확인합니다.

주어진 방향으로 이동할 때 공원을 벗어나는지 확인합니다.
주어진 방향으로 이동 중 장애물을 만나는지 확인합니다.
위 두 가지중 어느 하나라도 해당된다면, 로봇 강아지는 해당 명령을 무시하고 다음 명령을 수행합니다.
공원의 가로 길이가 W, 세로 길이가 H라고 할 때, 공원의 좌측 상단의 좌표는 (0, 0), 우측 하단의 좌표는 (H - 1, W - 1) 입니다.

공원을 나타내는 문자열 배열 `park`, 로봇 강아지가 수행할 명령이 담긴 문자열 배열 `routes`가 매개변수로 주어질 때, 로봇 강아지가 모든 명령을 수행 후 놓인 위치를 [세로 방향 좌표, 가로 방향 좌표] 순으로 배열에 담아 return 하도록 solution 함수를 완성해주세요.

## 💡 접근/풀이 방식
- 시작점에서 다음 위치로 이동할 때 해당 위치가 범위 안에 있는지와 장애물이 있는지 확인하고 분류해주면 된다.

## 💻 풀이 코드 (C#)

```C#
using System;

public class Solution {
    public int[] solution(string[] park, string[] routes) {
        // r : 행, c : 열
        int r = 0;
        int c = 0;
        
        for(int i = 0; i < park.Length; i++)
        {
            for(int j = 0; j < park[i].Length; j++)
            {
                // 시작점 찾아서 좌표로 저장
                if(park[i][j] == 'S')
                {
                    r = i;
                    c = j;
                    break;
                }
            }
        }
        
        foreach(string route in routes)
        {
            // 움직일 좌표(이동 전 해당 위치를 체크하는 변수)
            int moveR = r;  int moveC = c;
            // 움직일 수 있는지 확인
            bool canMove = false;
        
            // 움직일 내용들
            string[] split = route.Split(' ');
            string dir = split[0];
            int move = int.Parse(split[1]);
        
            for(int i = 0; i < move; i++)
            {
                if(dir == "N")  moveR--;
                else if(dir == "S") moveR++;
                else if(dir == "W") moveC--;
                else if(dir == "E") moveC++;
            
                // 이동 가능한지 체크
                if(moveR < 0 || moveC < 0 || moveR >= park.Length || moveC >= park[0].Length || park[moveR][moveC] == 'X')
                    
                {
                    canMove = false;
                    // 못 지나가니 다음 경로로
                    break;
                }
                    
                else
                    canMove =true;
            }
            
            if(canMove)
            {
                r = moveR;
                c = moveC;
            }
        }
        
        return new int[]{r,c};
    }
}
```

## ⏱️ 복잡도
- 시간: O(R × C + K × M) - 격자 스캔(R×C)과 명령 수행(K개 명령 × 최대 이동량 M)
- 공간: O(1)
