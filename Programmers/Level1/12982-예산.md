# [Lv1] 예산

> **유형:** `#배열` `#정렬` `#그리디`
> **링크:** [12982](https://school.programmers.co.kr/learn/courses/30/lessons/12982)

## 📝 문제 요약
S사에서는 각 부서에 필요한 물품을 지원해 주기 위해 부서별로 물품을 구매하는데 필요한 금액을 조사했습니다. 
그러나, 전체 예산이 정해져 있기 때문에 모든 부서의 물품을 구매해 줄 수는 없습니다. 그래서 최대한 많은 부서의 물품을 구매해 줄 수 있도록 하려고 합니다.

물품을 구매해 줄 때는 각 부서가 신청한 금액만큼을 모두 지원해 줘야 합니다. 예를 들어 1,000원을 신청한 부서에는 정확히 1,000원을 지원해야 하며, 1,000원보다 적은 금액을 지원해 줄 수는 없습니다.

부서별로 신청한 금액이 들어있는 배열 `d`와 예산 `budget`이 매개변수로 주어질 때, 최대 몇 개의 부서에 물품을 지원할 수 있는지 return 하도록 solution 함수를 완성해주세요.

### 제한사항
`d`는 부서별로 신청한 금액이 들어있는 배열이며, 길이(전체 부서의 개수)는 1 이상 100 이하입니다.
`d`의 각 원소는 부서별로 신청한 금액을 나타내며, 부서별 신청 금액은 1 이상 100,000 이하의 자연수입니다.
`budget`은 예산을 나타내며, 1 이상 10,000,000 이하의 자연수입니다.

## 💡 접근/풀이 방식
- 최대한 많은 부서에 지원을 하려면 신청한 금액이 적은 부서부터 지원을 해주면 된다.
- 부서가 신청한 금액들을 오름차순으로 정렬한 후 예산과 비교해 차감하면서 카운트 해주면 된다.

## 💻 풀이 코드 (C#)

```C#
using System;

public class Solution {
    public int solution(int[] d, int budget) {
        int answer = 0;
        
        // 예산이 적은 부서부터 분류하기 위해 정렬
        Array.Sort(d);
        
        // 부서마다 금액 확인
        foreach(int amount in d)
        {
            // 지원 가능하면 예산 차감 및 부서 체크
            if(budget >= amount)
            {
                budget -= amount;
                answer++;
            }
            else
                break;
            
        }
        
        return answer;
    }
}
```

## ⏱️ 복잡도
- 시간: O(N log N) - `Array.Sort`
- 공간: O(1)
