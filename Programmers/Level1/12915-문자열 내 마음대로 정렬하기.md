# [Lv1] 문자열 내 마음대로 정렬하기

> **유형:** `#Array`, `#정렬`, `#문자열처리`, `#람다`, `#LINQ`
> **링크:** [12915](https://school.programmers.co.kr/learn/courses/30/lessons/12915)

## 📝 문제 요약
문자열로 구성된 리스트 `strings`와, 정수 `n`이 주어졌을 때, 각 문자열의 인덱스 `n`번째 글자를 기준으로 오름차순 정렬해주세요.

## 💡 접근/풀이 방식
### 1. 문자열 덧붙이기
- 1차 정렬 기준은 n번째 알파벳, 2차 정렬 기준은 앞의 문자들의 사전순 정렬이기에 `Array.Sort()`가 앞의 조건들을 잘 충족할 수 있도록 n번째 알파벳을 맨 앞에, 그 뒤엔 기존 단어들을 붙이는 방식을 사용했다.
### 2. 람다식 커스텀 정렬
- `Array.Sort()` 내에 람다식 형식으로 규칙을 정할 수 있다.
### 3. Linq 활용
- 1차 정렬로 `OrderBy()`, 1차 정렬 이후 생긴 그룹을 가지고 2차 정렬로 `ThenBy()`를 통해 정리할 수 있다. 
## 💻 풀이 코드 (C#)
### 1. 문자열 덧붙이기
```C#
using System;

public class Solution {
    public string[] solution(string[] strings, int n) {
        string[] answer = new string[strings.Length];
        
        for(int i = 0; i < answer.Length; i++)
        {
            // n번째 알파벳과 그 뒤에 단어를 넣기, 두 조건의 정렬을 충족하기 위한 목적
            answer[i] = strings[i][n] + strings[i];
        }
        Array.Sort(answer);
        
        for(int j = 0; j < answer.Length; j++)
        {
            // 0번재를 제외한 1번째부터 이후의 내용을 잘라넣기
            answer[j] = answer[j].Substring(1);
        }
        return answer;
    }
}
```
### 2. 람다식 커스텀 정렬
```C#
using System;

public class Solution {
    public string[] solution(string[] strings, int n) {
        // 정렬 기준 수정
        Array.Sort(strings, (s1, s2) => {
            // 글자가 서로 다르면
            if(s1[n] != s2[n])
                // 알파벳 사전 순으로 정렬
                return s1[n].CompareTo(s2[n]);
            // 글자가 서로 같다면
            else
                // 단어 자체를 사전 순으로 정렬
                return s1.CompareTo(s2);
        });
        
        return strings;
    }
}
```
### 3. Linq 활용
```C#
using System.Linq;

public class Solution {
    public string[] solution(string[] strings, int n) {
        return strings
            .OrderBy(s => s[n]) // 1순위 : n번째 글자로 정렬
            .ThenBy(s => s)     // 2순위 : 같은 그룹이 생기면 단어 전체로 정렬
            .ToArray();
    }
}
```
