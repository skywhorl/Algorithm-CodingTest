# 문자열 내 마음대로 정렬하기
### [Lv.1 - 12915](https://school.programmers.co.kr/learn/courses/30/lessons/12915)

## 문제
문자열로 구성된 리스트 `strings`와, 정수 `n`이 주어졌을 때, 각 문자열의 인덱스 `n`번째 글자를 기준으로 오름차순 정렬하려 합니다. 
예를 들어 `strings`가 `["sun", "bed", "car"]`이고 `n`이 1이면 각 단어의 인덱스 1의 문자 `"u", "e", "a"`로 `strings`를 정렬합니다.

### 제한 조건
- `strings`는 길이 1 이상, 50이하인 배열입니다.
- `strings`의 원소는 소문자 알파벳으로 이루어져 있습니다.
- `strings`의 원소는 길이 1 이상, 100이하인 문자열입니다.
- 모든 `strings`의 원소의 길이는 n보다 큽니다.
- 인덱스 1의 문자가 같은 문자열이 여럿 일 경우, 사전순으로 앞선 문자열이 앞쪽에 위치합니다.
## 풀이(Sorting)
- 1차 정렬 기준은 n번째 알파벳, 2차 정렬 기준은 앞의 문자들의 사전순 정렬이기에 `Array.Sort()가 앞의 조건들을 잘 충족할 수 있도록 해당 string 타입의 배열을 생성했다.

``` C#
using System;

public class Solution {
    public string[] solution(string[] strings, int n) {
        string[] answer = new string[strings.Length];
        
        for(int i = 0; i < answer.Length; i++)
        {
            // n번째 알파벳과 그 뒤에 단어를 넣기, 두 조건의 정렬을 충족하기 위한 목적
            answer[i] = strings[i][n] + strings[i];
        }
        Array.Sort(answer);
        
        for(int j = 0; j < answer.Length; j++)
        {
            // 0번재를 제외한 1번째부터 이후의 내용을 잘라넣기
            answer[j] = answer[j].Substring(1);
        }
        return answer;
    }
}
```
## 다른 풀이
- `Array.Sort()` 람다식으로 풀어서 정렬을 커스텀 할 수 있다.
- 아래의 코드를 보면 string 타입끼리 `CompareTo()`를 사용했는데, 해당 메서드는 객체인 string을 사전 순(유니코드)으로 정렬을 할 수 있다.
``` C#
using System;

public class Solution {
    public string[] solution(string[] strings, int n) {
        // 정렬 기준 수정
        Array.Sort(strings, (s1, s2) => {
            // 글자가 서로 다르면
            if(s1[n] != s2[n])
                // 알파벳 사전 순으로 정렬
                return s1[n].CompareTo(s2[n]);
            // 글자가 서로 같다면
            else
                // 단어 자체를 사전 순으로 정렬
                return s1.CompareTo(s2);
        });
        
        return strings;
    }
}
```
- Linq를 알면 좀 더 간단하게 정렬을 할 수 있다.
- `OrderBy()`로 1차 정렬 기준을 정해준 뒤, 정렬이 안 된 같은 그룹끼리는 `ThenBy()`를 통해 다시 정렬해 줄 수 있다.
``` C#
using System.Linq;

public class Solution {
    public string[] solution(string[] strings, int n) {
        return strings
            .OrderBy(s => s[n]) // 1순위 : n번째 글자로 정렬
            .ThenBy(s => s)     // 2순위 : 같은 그룹이 생기면 단어 전체로 정렬
            .ToArray();
    }
}
```
