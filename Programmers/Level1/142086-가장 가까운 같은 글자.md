# [Lv1] 가장 가까운 같은 글자

> **유형:** `#Dictionary`, `#문자열처리`
> **링크:** [142086](https://school.programmers.co.kr/learn/courses/30/lessons/142086)

## 📝 문제 요약
문자열 `s`가 주어졌을 때, `s`의 각 위치마다 자신보다 앞에 나왔으면서, 자신과 가장 가까운 곳에 있는 같은 글자가 어디 있는지 알려주는 함수 solution을 완성해주세요.

## 💡 접근/풀이 방식
### 1. 반복문을 통한 인덱스 파악
- 이중 반복문을 돌려 같은 글자를 발견 시 두 글자의 인덱스 차를 구하면 떨어진 거리를 알 수 있다.
### 2. Dictionary 활용
- 1의 방법은 이중 반복문을 사용하기에 시간 복잡도가 크기에 Dictionary의 검색을 활용하여 단순화 할 수 있다. 
## 💻 풀이 코드 (C#)
### 1. 반복문을 통한 인덱스 파악
```C#
using System;

public class Solution {
    public int[] solution(string s) {
        int[] answer = new int[s.Length];
        
        for(int i = s.Length-1; i >= 0; i--){
            for(int j = i; j >= 0; j--){
                // 같은 인덱스가 아닌 상황에서 글자가 같을 때
                if(i != j && s[i] == s[j]){
                    // 각 인덱스의 차 = 떨어진 거리
                    answer[i] = i - j;
                    break;
                }
                else
                    answer[i] = -1;
            }
        }
        
        return answer;
    }
}
```
### 2. Dictionary 활용
``` C#
using System;
using System.Collections.Generic;

public class Solution {
    public int[] solution(string s) {
        int[] answer = new int[s.Length];
        
        // <알파벳, 마지막으로 본 인덱스>
        Dictionary<char, int> lastPos = new Dictionary<char, int>();
        
        for(int i = 0; i < s.Length; i++) {
            char currentChar = s[i];
            
            // 본 적 있는 글자라면
            if(lastPos.ContainsKey(currentChar)) {
                // 현재 위치 - 예전 위치
                answer[i] = i - lastPos[currentChar];
                // 가장 최신 위치로 사전 갱신
                lastPos[currentChar] = i;
            } 
            // 처음 보는 글자라면?
            else {
                answer[i] = -1;
                // 현재 위치 등록
                lastPos.Add(currentChar, i);
            }
        }
        
        return answer;
    }
}
```
