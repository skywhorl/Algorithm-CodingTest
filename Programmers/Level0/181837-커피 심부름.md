# [Lv0] 커피 심부름

## 📝 문제 요약
아메리카노(4500원)와 카페 라테(5000원)만 파는 카페에서 팀원들의 주문을 받아 총 결제 금액을 계산합니다. 주문은 "iceamericano", "americanoice", "hotamericano", "americanohot", "icecafelatte", "cafelatteice", "hotcafelatte", "cafelattehot", "americano", "cafelatte", "anything" 중 하나로 들어옵니다. `"anything"`은 차가운 아메리카노로 통일합니다.
문자열 배열 `order`가 주어질 때, 카페에서 결제하게 될 금액을 return 하는 solution 함수를 작성해 주세요.

## 💡 접근/풀이 방식
- `"latte"`라는 문구가 붙은 메뉴가 공통적으로 카페라테로 분류를 할 수 있기에 `string.Contains()`를 이용하여 찾을 수 있다.

## 💻 풀이 코드 (C#)

``` C#
using System;
using System.Linq;

public class Solution {
    public int solution(string[] order) {
        // "latte" 키워드에 따라 가격이 바뀜
        return order.Sum(beverage => beverage.Contains("latte") ? 5000 : 4500);
    }
}
```

## ⏱️ 복잡도
- 시간: O(N × L) - `Sum`으로 배열 전체 순회 O(N), 각 요소에서 `Contains` 문자열 탐색 O(L)
- 공간: O(1)
