# [Lv0] 두 수의 합

> **유형:** `#문자열` `#자료형`
> **링크:** [181846](https://school.programmers.co.kr/learn/courses/30/lessons/181846)

## 📝 문제 요약
0 이상의 두 정수가 문자열 `a`, `b`로 주어질 때, `a + b`의 값을 문자열로 return 하는 solution 함수를 작성해 주세요.

## 💡 접근/풀이 방식
- int 타입으로 바꿔 계산하면 int 범위를 초과하는 수를 처리 못 하고, double로 계산하면 수가 높을 시 E가 붙게 된다(ex. E+20 : 10을 20번 곱해라).
- 또한 double 타입이어도 대략 15~17자리까지만 표현하고 그 이상은 메모리 초과로 정확하게 수를 기억하지 못한다(약 29자리 표현되는 decimal도 포함).
- 최대한 표현이 가능한 `BigInteger`가 존재하지만 코딩 테스트 환경에서는 보통 제공되지 않는 라이브러리다.
- 이럴 땐 한 자릿수마다 일일이 계산을 해주는 방법이 있다.

## 💻 풀이 코드 (C#)

``` C#
using System;
using System.Text;
using System.Collections.Generic;

public class Solution {
    public string solution(string a, string b) {
        // string 최적화 용도
        StringBuilder sb = new StringBuilder();
        // 뒤에서 시작하는 인덱스 용도
        int i = a.Length - 1;
        int j = b.Length - 1;
        // 올림 용도
        int next = 0; 

        while (i >= 0 || j >= 0 || next > 0) {
            // 올림 내용 불러오기
            int sum = next;
            // 자릿수 계산
            if (i >= 0) sum += a[i--] - '0';
            if (j >= 0) sum += b[j--] - '0';
            // 계산 수 붙여넣기
            sb.Append(sum % 10); 
            // 십의 자리 초과 시 미리 저장
            next = sum / 10;    
        }

        // 뒤에서부터 추가했으므로 마지막에 한 번 뒤집기
        char[] result = sb.ToString().ToCharArray();
        Array.Reverse(result);
        return new string(result);
    }
}
```

## ⏱️ 복잡도
- 시간: O(N) - N은 두 문자열 중 긴 쪽의 길이
- 공간: O(N) - StringBuilder 및 결과 문자열
