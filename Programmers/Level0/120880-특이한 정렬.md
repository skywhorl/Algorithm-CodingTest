# [Lv0] 특이한 정렬

> **유형:** `#배열` `#정렬`
> **링크:** [120880](https://school.programmers.co.kr/learn/courses/30/lessons/120880)

## 📝 문제 요약
정수 배열 `numlist`와 정수 `n`이 주어질 때, `numlist`의 원소를 `n`과 가까운 수부터 정렬한 배열을 return한다. `n`으로부터의 거리가 같으면 더 큰 수를 앞에 배치한다.

## 💡 접근/풀이 방식
- 간단한 전개를 위해 `Sort()`의 델리게이트 람다식을 적용했다.
- `numlist`의 내용들을 비교하여 거리가 같을 때에만 내림차순을 적용했다.

## 💻 풀이 코드 (C#)

``` C#
using System;

public class Solution {
    public int[] solution(int[] numlist, int n) {
        
        // 정렬 규칙 생성
        Array.Sort(numlist, (x, y) => {
            // n과의 거리 계산
            int distanceX = Math.Abs(n - x);
            int distanceY = Math.Abs(n - y);

            // 거리 같을 시
            if (distanceX == distanceY) {
                // 내림차순
                return y.CompareTo(x);
            }
            
            // 거리가 같으면 오름차순
            return distanceX.CompareTo(distanceY);
        });

        return numlist;
    }
}
```

## ⏱️ 복잡도
- 시간: O(N log N) - `Array.Sort()` 사용, 비교 함수는 O(1)
- 공간: O(1)
