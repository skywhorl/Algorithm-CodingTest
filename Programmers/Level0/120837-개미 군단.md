# [Lv0] 개미 군단

## 📝 문제 요약
개미 군단이 사냥을 나가려고 합니다. 개미군단은 사냥감의 체력에 딱 맞는 병력을 데리고 나가려고 합니다.
장군개미는 `5`, 병정개미는 `3`, 일개미는 `1`의 공격력을 가지며, 사냥감의 체력 `hp`에 딱 맞게 최소한의 병력을 구성하려면 몇 마리의 개미가 필요한지 return 하도록 solution 함수를 완성해주세요.

## 💡 접근/풀이 방식
- 가장 높은 공격력으로 `hp`를 몫으로 나누면 필요한 해당 개미의 수가 된다.
- 이후 공격력으로 `hp`를 나머지 계산을 하면 남은 `hp`가 된다.
- 이 순서를 통해 공격력이 높은 개미부터 몫과 나머지 계산으로 `hp`를 천천히 깎으면서 필요한 개미의 종류와 수를 구할 수 있다.

## 💻 풀이 코드 (C#)

``` C#
public class Solution {
    public int solution(int hp) {
        int answer = 0;
        
        // 장군개미
        answer += hp / 5;
        hp %= 5;
        
        // 병정개미
        answer += hp / 3;
        hp %= 3;
        
        // 남은 hp는 일개미
        answer += hp;
        
        return answer;
    }
}
```

## ⏱️ 복잡도
- 시간: O(1)
- 공간: O(1)
