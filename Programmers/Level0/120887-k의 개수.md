# [Lv0] k의 개수

> **유형:** `#문자열` `#LINQ` `#수학`
> **링크:** [120887](https://school.programmers.co.kr/learn/courses/30/lessons/120887)

## 📝 문제 요약
정수 `i`, `j`, `k`가 매개변수로 주어질 때, `i`부터 `j`까지 숫자 `k`가 몇 번 등장하는지 return 하도록 solution 함수를 완성해주세요. (1부터 13까지에서 1은 1, 10, 11, 12, 13으로 총 6번 등장)

## 💡 접근/풀이 방식
### 1. 문자열 Replace 활용
- 비교를 위해 string 타입으로 변경 후 `k`를 포함하고 있다면 해당 내용을 지우고 지우기 전의 문자열과 길이를 비교했다.
### 2. 연산 방식으로 풀기
- `ToString()` 같은 경우는 변환해야 하는 길이가 길 수록 느려질 수 있기에 순수 연산 방식을 사용하면 다음과 같다.
- 따로 string으로 변환할 필요 없이 자릿수로 비교한다.
### 3. LINQ 활용
- 불필요한 return을 줄이기 위해 Solution 함수 자체를 람다식으로 만들었다.
- 새로운 데이터를 만들 때 데이터 나열(목록)을 다루는 `Enumerable`을 사용했다.
- `Range()`로 시작할 범위와 이동할 범위를 설정했다.
- `Select()`를 통해 데이터를 가공했다(범위의 int 값이 string 타입으로 변경되었다).
- `Where()`을 사용해 조건을 적용했다(가공된 데이터로 값이 일치하는지 비교했다).
- 여기서 `First()`는 string 타입의 맨 앞 char 타입을 return 하기에 char 타입에 맞추기 위한 과정이라 볼 수 있다.
- 위의 내용들을 통해 조건을 만족 시 `Count()`로 개수를 세도록 했다.
- 위의 내용까지가 범위 내의 한 수가 조건을 만족하는지 확인하는 거였기에 `Sum()`으로 범위의 종합을 확인한다.

## 💻 풀이 코드 (C#)
### 1. 문자열 Replace 활용
``` C#
using System;

public class Solution {
    public int solution(int i, int j, int k) {
        int answer = 0;
        
        for(; i <= j; i++)
        {
            string temp1 = i.ToString();
            // 해당 숫자를 포함하면 지우기
            string temp2 = temp1.Replace(k.ToString(),"");
            // 길이의 차 = k를 포함하는 개수
            answer += temp1.Length - temp2.Length;
        }
        return answer;
    }
}
```
### 2. 연산 방식으로 풀기
``` C#
using System;

public class Solution {
    public int solution(int i, int j, int k) {
        int answer = 0;
        
        for(; i <= j; i++)
        {
            int temp = i;
            while (temp > 0) 
            {
            // 일의 자리가 k인지 확인
            if(temp % 10 == k) answer++; 

            // 한 자리씩 깎아내기
            temp /= 10; 
            }
        }
        return answer;
    }
}
```
### 3. LINQ 활용
``` C#
using System;
using System.Linq;

public class Solution {
    public int solution(int i, int j, int k) =>
        
        Enumerable
            .Range(i, j-i+1)
            .Select(x => x.ToString().Where(y => y.Equals(k.ToString().First())).Count())
            .Sum();  
}
```

## ⏱️ 복잡도
- 시간: O(N) - N은 범위 `(j - i + 1)`
- 공간: O(1)
