# 한 번만 등장한 문자
### [Lv.0 - 120896](https://school.programmers.co.kr/learn/courses/30/lessons/120896)

## 문제
문자열 `s`가 매개변수로 주어집니다. `s`에서 한 번만 등장하는 문자를 사전 순으로 정렬한 문자열을 return 하도록 solution 함수를 완성해보세요. 
한 번만 등장하는 문자가 없을 경우 빈 문자열을 return 합니다.
## 풀이
- 해당 값과 일치하는 index를 알려주는 `IndexOf()`와 검사하는 방향이 다른 `LastIndexOf()`의 index가 동일하면 하나만 존재한다는 의미다.

``` C#
using System;
using System.Collections.Generic;

public class Solution {
    public string solution(string s) {
        List<char> answer = new List<char>();

        for(int i = 0; i < s.Length; i++)
        {
            // s[i]의 값을 찾았는데 하나만 존재할 때
            if (s.IndexOf(s[i]) == s.LastIndexOf(s[i]))
            {
                answer.Add(s[i]);
            }
        }
        answer.Sort();
        
        return new string(answer.ToArray());
    }
}
```
## 다른 풀이
- Linq에 이어 붙이는 기능인 `Concat()`을 이용하여 정답의 내용을 추가하는 방식을 사용했다.
- `Group()`으로 각각의 알파벳들끼리 묶고 `Where()`을 통해 원소의 개수가 1인 그룹을 고른다.
- 이후 `Select()`로 해당 그룹의 값을 추출하고 `OrderBy()`로 오름차순 정렬한다.
```C#
using System;
using System.Linq;

public class Solution {
    public string solution(string s) =>
        string.Concat(s.GroupBy(g => g)
                     .Where(x => x.Count() == 1)
                     .Select(k => k.Key)
                     .OrderBy(o => o));
}
```
