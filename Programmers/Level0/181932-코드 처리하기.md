# [Lv0] 코드 처리하기

> **유형:** `#문자열` `#구현`
> **링크:** [181932](https://school.programmers.co.kr/learn/courses/30/lessons/181932)

## 📝 문제 요약
문자열 `code`를 앞에서부터 읽으며 `mode`(0 또는 1, 시작값 0)에 따라 `ret`을 만듭니다.
- `code[idx]`가 `"1"`이면 `mode`를 토글합니다.
- `mode = 0`일 때 `"1"`이 아니면 `idx`가 짝수일 때만 `code[idx]`를 `ret`에 추가.
- `mode = 1`일 때 `"1"`이 아니면 `idx`가 홀수일 때만 `code[idx]`를 `ret`에 추가.

최종 `ret`를 반환하며, 빈 문자열이면 `"EMPTY"`를 반환합니다.

## 💡 접근/풀이 방식
- 모드는 두 종류이기에 `bool` 타입으로 편하게 지정했다.
- 모드에 맞게 변경된 상태에서는 짝수든 홀수든 문자열을 추가하는 것이기에 `or` 연산자로 행동을 하나로 묶었다.
- 마지막엔 `answer`가 비는 경우도 생각해야 하기에 return 부분에 삼항 연산자로 상황을 구분했다. 

## 💻 풀이 코드 (C#)

``` C#
using System;
using System.Collections.Generic;

public class Solution {
    public string solution(string code) {
        string answer = "";
        
        // mode 0 : false, mode 1 : true
        bool mode = false;
        
        for(int i = 0; i < code.Length; i++)
        {
            // 모드를 변경해야 할 때 
            if(code[i].Equals('1'))
            {
                // 모드 바꾸기
                mode = !mode;
            }
            else
            {
                // mode와 idx의 조건에 각각 맞게 정답 추가
                if(mode && i%2 == 1 || !mode && i%2 == 0)
                {
                    answer += code[i].ToString();
                }
            }
        }
        
        // 정답이 비면 조건에 맞게 EMPTY로 수정
        return answer.Equals("") ? "EMPTY" : answer;
    }
}
```

## ⏱️ 복잡도
- 시간: O(N) -  문자열 누적 연결은 O(N²) 위험이 있어 `StringBuilder` 권장
- 공간: O(N)
