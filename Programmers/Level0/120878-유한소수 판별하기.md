# [Lv0] 유한소수 판별하기

> **유형:** `#수학`
> **링크:** [120878](https://school.programmers.co.kr/learn/courses/30/lessons/120878)

## 📝 문제 요약
두 정수 `a`와 `b`가 주어질 때, `a/b`를 기약분수로 나타냈을 때 분모의 소인수가 `2`와 `5`만 존재하면 유한소수(`1`), 아니면 무한소수(`2`)를 return한다.

## 💡 접근/풀이 방식
- 기약분수가 되려면 최대공약수를 구해서 나눠주면 된다.
- 주어진 각각의 2와 5를 나누었을 때 분모가 1이 되었다면 유한소수고, 이 외의 다른 수가 있다면 무한소수가 된다.
### 유클리드 호제법 알고리즘
- 두 수 사이에 존재하는 최대 공약수(GCD, greatest common divisor)를 구하는 알고리즘이다.
- 두 수 a, b (a > b)와 이 둘을 나눈 나머지를 r이라 할 때 a와 b의 최대 공약수는 b와 r의 최대 공약수와 같다.
- 이 성질에 따라 다시 b와 r을 나누어 나머지가 0이 될 때까지 계산하면 최대 공약수를 구할 수 있다.

## 💻 풀이 코드 (C#)

``` C#
using System;

public class Solution {
    public int solution(int a, int b) {
        
        // gcd : 최대 공약수 준말
        // 최대 공약수를 구하는 이유 : 기약분수로 만들기 위해
        int gcd = GetGCD(a,b);
        
        // 기약분수 표현을 위해 공약수로 나누기
        b /= gcd; 

        // 소인수 2로 나누기
        while (b % 2 == 0) {
            b /= 2;
        }
        // 소인수 5로 나누기
        while (b % 5 == 0) {
            b /= 5;
        }

        // 1이 남았다면 유한소수, 아니면 무한소수
        return (b == 1) ? 1 : 2;
        
    }
    
    // 최대 공약수 구하기
    private int GetGCD(int a, int b) {
        // 나머지 계산으로 공약수 찾기
        while (b != 0) 
        {
            int remainder = a % b;
            a = b;
            b = remainder;
        }
        return a;
    }
}
```

## ⏱️ 복잡도
- 시간: O(log N) - 반복문 단계마다 반씩 줄어듦
- 공간: O(1)
