# [Lv0] 배열 만들기 4

> **유형:** `#스택` `#배열`
> **링크:** [181918](https://school.programmers.co.kr/learn/courses/30/lessons/181918)

## 📝 문제 요약
정수 배열 `arr`를 앞에서부터 탐색하며 스택 `stk`를 만듭니다.
- `stk`가 비어 있거나 마지막 원소가 `arr[i]`보다 작으면 `arr[i]`를 `stk`에 push하고 `i++`.
- `stk`의 마지막 원소가 `arr[i]` 이상이면 `stk`의 마지막 원소를 pop.

완성된 `stk`를 반환합니다.

## 💡 접근/풀이 방식
- 문제에서 제시한 조건들을 차근차근히 코드로 변환하면 간단하게 풀 수 있고, 반복문 같은 경우엔 `i`를 경우에 따라 더해주게 만들어야 한다.
- `else` 부분은 원래 `else if(stk[stk.Count-1] >= arr[i])`로 문제의 경우에 맞게 작성했으나, `if` 부분에서 다 걸러지므로 `else`로 바꾸었다.
- 특정 위치의 내용을 지울 때는 `RemoveAt(index)`이고 특정 값을 찾아 지울 때는 `Remove(value)`다.

## 💻 풀이 코드 (C#)

``` C#
using System;
using System.Collections.Generic;

public class Solution {
    public int[] solution(int[] arr) {
        List<int> stk = new List<int>();
        
        for(int i = 0; i < arr.Length;)
        {
            if(stk.Count == 0 || stk[stk.Count-1] < arr[i])
            {
                stk.Add(arr[i]);
                i++;
            }
            else
            {
                stk.RemoveAt(stk.Count-1);
            }
        }
        return stk.ToArray();
    }
}
```

## ⏱️ 복잡도
- 시간: O(N)
- 공간: O(N)
