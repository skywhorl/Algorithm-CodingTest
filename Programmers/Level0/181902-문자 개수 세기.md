# [Lv0] 문자 개수 세기

> **유형:** `#문자열` `#배열`
> **링크:** [181902](https://school.programmers.co.kr/learn/courses/30/lessons/181902)

## 📝 문제 요약
알파벳 대소문자로만 이루어진 문자열 `my_string`이 주어질 때, 'A'~'Z', 'a'~'z' 순서로 각 문자의 개수를 담은 길이 52의 정수 배열을 반환합니다.

## 💡 접근/풀이 방식
- `Console.WriteLine((int)char)` 방식으로 출력하면 'A'는 65, 'a'는 97이 뜬다(92부터 92은 특수기호).
- 위의 방식을 이용하여 숫자로 대소문자를 분류해 배열의 인덱스에 맞춰 지정해 줄 수 있다.

## 💻 풀이 코드 (C#)

``` C#
using System;

public class Solution {
    public int[] solution(string my_string) {
        int[] answer = new int[52];
        
        for(int i = 0; i < my_string.Length; i++)
        {
            // 대문자((int)'A' == 65)
            if((int)my_string[i] < 97)
            {
                answer[(int)my_string[i]-65]++;
            }
            // 소문자((int)'a' == 97)
            else
            {
                // 소문자는 배열 절반에서 시작해야 한다
                answer[(int)my_string[i]-97+26]++;
            }
        }

        return answer;
    }
}
```

## ⏱️ 복잡도
- 시간: O(N) - `my_string` 한 번 순회
- 공간: O(1) - 길이 52의 고정 크기 배열만 사용
