# 문자 개수 세기
### [Lv.0 - 181902](https://school.programmers.co.kr/learn/courses/30/lessons/181902)

## 문제
알파벳 대소문자로만 이루어진 문자열 my_string이 주어질 때, `my_string`에서 'A'의 개수, `my_string`에서 'B'의 개수,..., 
`my_string`에서 'Z'의 개수, `my_string`에서 'a'의 개수, `my_string`에서 'b'의 개수,..., `my_string`에서 'z'의 개수를 순서대로 담은 길이 `52`의 정수 배열을 return 하는 solution 함수를 작성해 주세요.
## 풀이
- `Console.WriteLine((int)char)` 방식으로 출력하면 'A'는 65, 'a'는 97이 뜬다(92부터 92은 특수기호).
- 위의 방식을 이용하여 숫자로 대소문자를 분류해 배열의 인덱스에 맞춰 지정해 줄 수 있다.

``` C#
using System;

public class Solution {
    public int[] solution(string my_string) {
        int[] answer = new int[52];
        
        for(int i = 0; i < my_string.Length; i++)
        {
            // 대문자((int)'A' == 65)
            if((int)my_string[i] < 97)
            {
                answer[(int)my_string[i]-65]++;
            }
            // 소문자((int)'a' == 97)
            else
            {
                // 소문자는 배열 절반에서 시작해야 한다
                answer[(int)my_string[i]-97+26]++;
            }
        }

        return answer;
    }
}
```
