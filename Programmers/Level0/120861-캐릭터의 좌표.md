# [Lv0] 캐릭터의 좌표

> **유형:** `#배열` `#수학` `#구현`
> **링크:** [120861](https://school.programmers.co.kr/learn/courses/30/lessons/120861)

## 📝 문제 요약
머쓱이는 RPG게임을 하고 있습니다. 게임에는 `up`, `down`, `left`, `right` 방향키가 있으며 각 키를 누르면 위, 아래, 왼쪽, 오른쪽으로 한 칸씩 이동합니다.
예를 들어 `[0,0]`에서 `up`을 누른다면 캐릭터의 좌표는 `[0, 1]`, `down`을 누른다면 `[0, -1]`, `left`를 누른다면 `[-1, 0]`, `right`를 누른다면 `[1, 0]`입니다.
머쓱이가 입력한 방향키의 배열 `keyinput`와 맵의 크기 `board`이 매개변수로 주어집니다. 캐릭터는 항상 `[0,0]`에서 시작하고, `[0, 0]`은 `board`의 정 중앙이며 `board` 범위 밖으로는 이동할 수 없습니다.
키 입력이 모두 끝난 뒤에 캐릭터의 좌표 `[x, y]`를 return하도록 solution 함수를 완성해주세요.

## 💡 접근/풀이 방식
- 문자열을 비교해 이동하면 되지만, 이동 시 `board`의 범위를 초과해서는 안 된다.
- 만약 `answer[index]`에서 `Math.Abs()` 절댓값으로 비교하면 양과 음의 영역을 중복해서 확인하게 되므로 경계에서 벗어나지 못하는 상황이 발생할 수 있다.

## 💻 풀이 코드 (C#)

``` C#
using System;

public class Solution {
    public int[] solution(string[] keyinput, int[] board) {
        // 시작 좌표
        int[] answer = {0,0};
        // 이동 최대 범위
        int xMax = board[0] / 2;
        int yMax = board[1] / 2;
        
        for(int i = 0; i < keyinput.Length; i++)
        {
            // 이동해야 하는 곳과 board 범위 안에 들어와 있는지 확인
            if(keyinput[i].Equals("left") && answer[0] > -xMax)
                answer[0]--;
            else if(keyinput[i].Equals("right") && answer[0] < xMax)
                answer[0]++;
            else if(keyinput[i].Equals("up") && answer[1] < yMax)
                answer[1]++;
            else if(keyinput[i].Equals("down") && answer[1] > -yMax)
                answer[1]--;
        }
        
        return answer;
    }
}
```

## ⏱️ 복잡도
- 시간: O(N)
- 공간: O(1)
