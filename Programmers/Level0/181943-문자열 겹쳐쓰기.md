# 문자열 겹쳐쓰기
### [Lv.0 - 181943](https://school.programmers.co.kr/learn/courses/30/lessons/181943)

## 문제
문자열 `my_string`, `overwrite_string`과 정수 `s`가 주어집니다. 
문자열 `my_string`의 인덱스 `s`부터 `overwrite_string`의 길이만큼을 문자열 `overwrite_string`으로 바꾼 문자열을 return 하는 solution 함수를 작성해 주세요.
## 풀이
- 아래의 코드에서는 문제에서 주어진대로 각 상황에 마다 반복문으로 내용을 추가 및 바꾸기를 적용했다(문자열 간단 수정은 '다른 풀이' 참고).

``` C#
using System;

public class Solution {
    public string solution(string my_string, string overwrite_string, int s) {
        string answer = "";
        
        // 바꾸는 구간 전까지 설정
        for(int i = 0; i < s; i++)
        {
            answer += my_string[i];
        }
        // 바꾸려는 내용 설정
        for(int j = 0; j < overwrite_string.Length; j++)
        {
            answer += overwrite_string[j];
        }
        // 나머지 내용 추가
        for(int k = overwrite_string.Length + s; k < my_string.Length; k++)
        {
            answer += my_string[k];
        }
        
        return answer;
    }
}
```

## 다른 풀이
- `string.Remove()`로 출력을 안 하는 구간을 지운 후 `string.Insert()`를 이용해 넣을 구간부터 문자열을 삽입한다.
```C#
using System;

public class Solution {
    public string solution(string my_string, string overwrite_string, int s) {
        string answer = "";
        answer = my_string.Remove(s,overwrite_string.Length);
        answer = answer.Insert(s, overwrite_string);
        return answer;
    }
}
```
