# [Lv0] 문자열 겹쳐쓰기

> **유형:** `#문자열` `#구현`
> **링크:** [181943](https://school.programmers.co.kr/learn/courses/30/lessons/181943)

## 📝 문제 요약
문자열 `my_string`, `overwrite_string`과 정수 `s`가 주어집니다. `my_string`의 인덱스 `s`부터 `overwrite_string`의 길이만큼을 `overwrite_string`으로 바꾼 문자열을 반환합니다.

## 💡 접근/풀이 방식
### 1. 반복문 풀이
- 문제에서 주어진대로 각 구간(바꾸기 전, 바꾸는 부분, 바꾸기 후)마다 반복문으로 내용을 추가 및 바꾸기를 적용했다.
### 2. Remove/Insert 활용
- `string.Remove()`로 출력을 안 하는 구간을 지운 후 `string.Insert()`를 이용해 넣을 구간부터 문자열을 삽입한다.

## 💻 풀이 코드 (C#)
### 1. 반복문 풀이
``` C#
using System;

public class Solution {
    public string solution(string my_string, string overwrite_string, int s) {
        string answer = "";
        
        // 바꾸는 구간 전까지 설정
        for(int i = 0; i < s; i++)
        {
            answer += my_string[i];
        }
        // 바꾸려는 내용 설정
        for(int j = 0; j < overwrite_string.Length; j++)
        {
            answer += overwrite_string[j];
        }
        // 나머지 내용 추가
        for(int k = overwrite_string.Length + s; k < my_string.Length; k++)
        {
            answer += my_string[k];
        }
        
        return answer;
    }
}
```
### 2. Remove/Insert 활용
``` C#
using System;

public class Solution {
    public string solution(string my_string, string overwrite_string, int s) {
        string answer = "";
        answer = my_string.Remove(s,overwrite_string.Length);
        answer = answer.Insert(s, overwrite_string);
        return answer;
    }
}
```

## ⏱️ 복잡도
- 시간: O(N)
- 공간: O(N)
