# [Lv0] 주사위 게임 3

> **유형:** `#구현` `#조건문`
> **링크:** [181916](https://school.programmers.co.kr/learn/courses/30/lessons/181916)

## 📝 문제 요약
네 주사위를 굴려 나온 숫자 `a`, `b`, `c`, `d`에 따라 점수 계산 규칙이 달라집니다.
- 모두 같은 값 `p`: `1111 × p`점
- 세 개가 `p`, 나머지가 `q`: `(10 × p + q)²`점
- 두 쌍 `p`, `q`: `(p + q) × |p - q|`점
- 두 개만 `p`로 같고 나머지가 서로 다른 `q`, `r`: `q × r`점
- 네 개 모두 다름: 가장 작은 숫자 만큼의 점수

## 💡 접근/풀이 방식
- 각 눈금마다 몇 번의 중복이 들어가 있는지 확인을 한다.
- 여기서 2번 중복일 때, 두 쌍이 존재할 수 있기에 해당 경우도 확인해 줄 변수나 경우를 만들어 줘야 한다. 

## 💻 풀이 코드 (C#)

``` C#
using System;
using System.Collections.Generic;

public class Solution {
    public int solution(int a, int b, int c, int d) {
        int[] dice = { a, b, c, d };
        
        // 0~5까지의 길이에 1~6 숫자 결과 담기
        int[] countDice = new int[6];
        foreach (int diceNum in dice) 
        {
            countDice[diceNum-1]++;
        }

        
        // 나온 눈금의 횟수
        List<int[]> countList = new List<int[]>();
        for (int i = 0; i < 6; i++) 
        {
            if (countDice[i] > 0) 
            {
                // {나온 횟수, 눈금 값} 순서로 저장
                countList.Add(new int[] { countDice[i], i + 1 });
            }
        }

        // [0] : 나온 횟수, [1] : 눈금
        countList.Sort((x, y) => 
        {
            // 빈도 수가 다르면    
            if (x[0] != y[0]) 
            {
                // 빈도 순으로 내림차순
                return y[0].CompareTo(x[0]);
            }
            // 빈도가 같을 땐 눈금 순으로 내림차순
            return y[1].CompareTo(x[1]);
        });

        // 가장 많이 나온 눈금
        int p = countList[0][1];
        // 빈도
        int numCount = countList[0][0]; 

        // 모든 수 동일
        if (numCount == 4) 
        {
            return 1111 * p;
        }

       // 3개 같고 1개 다름
        if (numCount == 3) 
        {
            int q = countList[1][1];
            return (int)Math.Pow(10 * p + q, 2);
        }

        // 2개 같을 때
        if (numCount == 2) {
            // 같은 게 두 쌍인 경우
            if (countList[1][0] == 2) 
            {
                int q = countList[1][1];
                return (p + q) * Math.Abs(p - q);
            }
            
            // 한 쌍만 같을 경우
            else 
            {
                int q = countList[1][1];
                int r = countList[2][1];
                return q * r;
            }
        }
        // 다 다를 경우 가장 높은 숫자가 결과
        return countList[countList.Count - 1][1];
    }
}
```

## ⏱️ 복잡도
- 시간: O(1) - 주사위 개수(4)와 눈금 범위(6)가 고정이라 모든 연산이 상수 시간
- 공간: O(1) - 고정 크기의 배열/리스트만 사용
