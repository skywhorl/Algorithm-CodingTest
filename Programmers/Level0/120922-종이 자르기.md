# [Lv0] 종이 자르기

> **유형:** `#수학` `#구현`
> **링크:** [120922](https://school.programmers.co.kr/learn/courses/30/lessons/120922)

## 📝 문제 요약
정수 `M`, `N`이 매개변수로 주어질 때, `M x N` 크기의 종이를 1 x 1 크기로 자르기 위해 필요한 최소 가위질 횟수를 return 하도록 solution 함수를 완성해보세요. (예: 2 x 2는 최소 3번)

## 💡 접근/풀이 방식
- `넓이-1`만큼의 가위질이 필요하다.

## 💻 풀이 코드 (C#)

``` C#
using System;

public class Solution {
    public int solution(int M, int N) {
        
        return M*N-1;
    }
}
```

## ⏱️ 복잡도
- 시간: O(1)
- 공간: O(1)
