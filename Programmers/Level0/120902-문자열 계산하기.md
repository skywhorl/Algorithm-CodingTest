# 문자열 계산하기
### [Lv.0 - 120902](https://school.programmers.co.kr/learn/courses/30/lessons/120902)

## 문제
`my_string`은 `"3 + 5"`처럼 문자열로 된 수식입니다. 문자열 `my_string`이 매개변수로 주어질 때, 수식을 계산한 값을 return 하는 solution 함수를 완성해주세요.
## 풀이
- 주어진 `my_string`이 숫자와 문자 모두 띄어쓰기가 되어 있으므로 `string.Split()`으로 분리를 해준다.
- 처음 시작 값에서 연산자에 맞게 기존 인덱스+2의 수와 계산하도록 설계했고 이후 배열을 활용한 반복문을 사용할 때 `i++`이 아닌 수마다 넘기기 위해 `i+=2`로 진행했다.

``` C#
using System;

public class Solution {
    public int solution(string my_string) {
        // 띄어쓰기 단위로 문자열 분리
        string[] cal = my_string.Split(" ");
        // 미리 0번째 집어넣기
        int answer = int.Parse(cal[0]);
        for(int i = 0; i+2 < cal.Length; i += 2)
        {
            // 0번째 넣은 값에서 연산자에 맞는 계산하기
            answer += cal[i+1].Equals("+") ? int.Parse(cal[i+2]) : -(int.Parse(cal[i+2]));
        }
        
        return answer;
    }
}
```
