# [Lv0] 저주의 숫자 3

> **유형:** `#수학` `#구현`
> **링크:** [120871](https://school.programmers.co.kr/learn/courses/30/lessons/120871)

## 📝 문제 요약
3x 마을에서는 3의 배수와 숫자 3을 사용하지 않는다. 정수 `n`이 주어질 때, `n`을 3x 마을에서 사용하는 숫자(3을 건너뛴 n번째 수)로 바꿔 return한다.

## 💡 접근/풀이 방식
- 3의 배수는 나머지 계산으로 찾고, 숫자 3을 포함하는 부분은 문자열로 바꿔 `Contains()` 함수를 이용해 찾았다.

## 💻 풀이 코드 (C#)

``` C#
using System;

public class Solution {
    public int solution(int n) {
        int answer = 0;
        
        for(int i = 1; i <= n; i++)
        {
            // 기존 카운트
            answer++;
            
            // 3의 배수 또는 3을 포함하는 숫자일 때
            while(answer % 3 == 0 || answer.ToString().Contains("3"))
            {
                // 계속 다음 숫자로 넘기기
                answer++;
            }
        }
        
        return answer;
    }
    
}
```

## ⏱️ 복잡도
- 시간: O(N) - 이중 반복문이지만 공유 변수가 전체 반복을 제한하기에 N이 맞음
- 공간: O(1)
