# [Lv0] 로그인 성공?

> **유형:** `#배열` `#구현`
> **링크:** [120883](https://school.programmers.co.kr/learn/courses/30/lessons/120883)

## 📝 문제 요약
입력한 아이디/패스워드 배열 `id_pw`와 회원 정보 2차원 배열 `db`가 주어질 때, 아이디·비밀번호 모두 일치하면 `"login"`, 아이디가 없으면 `"fail"`, 아이디는 맞지만 비밀번호가 틀리면 `"wrong pw"`를 return한다.

## 💡 접근/풀이 방식
- 로그인 내용이 일치하지 않는 경우를 미리 `"fail"`로 초기화 했다.
- string 타입끼리 값을 비교하려면 `string.Equals()`를 사용해야 한다.

## 💻 풀이 코드 (C#)

``` C#
using System;

public class Solution {
    public string solution(string[] id_pw, string[,] db) {
        string answer = "fail";
        for(int i = 0; i < db.GetLength(0); i++)
        {
            // id 비교
            if(id_pw[0].Equals(db[i,0]))
            {
                // 비밀번호 비교
                answer = (id_pw[1].Equals(db[i,1])) ? "login" : "wrong pw";
                // 아이디 찾았으면 종료
                break;
            }
        }
        return answer;
    }
}
```

## ⏱️ 복잡도
- 시간: O(N)
- 공간: O(N × L) - N은 `db` 크기, L은 문자열 길이
