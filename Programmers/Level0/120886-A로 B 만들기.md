# [Lv0] A로 B 만들기

> **유형:** `#배열` `#정렬` `#문자열` `#LINQ`
> **링크:** [120886](https://school.programmers.co.kr/learn/courses/30/lessons/120886)

## 📝 문제 요약
문자열 `before`와 `after`가 주어질 때, `before`의 순서를 바꾸어 `after`를 만들 수 있으면 `1`을, 만들 수 없으면 `0`을 return한다.

## 💡 접근/풀이 방식
### 1. Array.Sort 방식
- 순서를 바꿀 수 있다면 원하는 방식으로 정렬해도 상관이 없기에 배열 형태로 바꿔 정렬한 후 비교를 진행했다.
### 2. LINQ 방식
- `Array.Sort()`와 같은 `OrderBy()`로 정렬하고 연산자 `==`과 `Equals()`와 같이 `SequenceEqual()`로 내용이 같은지 비교할 수 있다.

## 💻 풀이 코드 (C#)
### 1. Array.Sort 방식
``` C#
using System;

public class Solution {
    public int solution(string before, string after) {
        char[] arrBefore = before.ToCharArray();
        char[] arrAfter = after.ToCharArray();
        
        // 순서가 같도록 정렬
        Array.Sort(arrBefore);
        Array.Sort(arrAfter);
        
        // 값 비교를 위해 string 타입으로 변환
        string strBefore = new string(arrBefore);
        string strAfter = new string(arrAfter);
        
        return strBefore == strAfter ? 1 : 0;
    }
}
```
### 2. LINQ 방식
```C#
using System;
using System.Linq;

public class Solution {
    public int solution(string before, string after) =>
        before.OrderBy(b => b).SequenceEqual(after.OrderBy(a => a)) ? 1 : 0;
}
```

## ⏱️ 복잡도
- 시간: O(N log N) - `Array.Sort()`
- 공간: O(N) - 정렬용 배열/문자열 생성
