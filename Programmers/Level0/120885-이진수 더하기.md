# [Lv0] 이진수 더하기

> **유형:** `#수학` `#문자열`
> **링크:** [120885](https://school.programmers.co.kr/learn/courses/30/lessons/120885)

## 📝 문제 요약
이진수를 의미하는 두 문자열 `bin1`과 `bin2`가 주어질 때, 두 이진수의 합을 return한다.

## 💡 접근/풀이 방식
- 뒷자리서부터 두 이진수를 자리마다 비교를 했고 `carry` 변수를 통해 자릿수 올림을 표현했다.
- 여기서 `char` 타입을 `int` 타입으로 바꿀 때 `'0'`을 빼는 방식을 사용했다.

## 💻 풀이 코드 (C#)

``` C#
using System;
using System.Text;

public class Solution {
    public string solution(string bin1, string bin2) {
        
        StringBuilder sb = new StringBuilder();
        // 각 string의 인덱스
        int b1 = bin1.Length-1;
        int b2 = bin2.Length-1;
        // 다음 자릿수 넘기는 용도
        int carry = 0;
        
        while(b1 >= 0 || b2 >= 0 || carry != 0)
        {
            // 남아 있는 자릿수마다 합 구하기
            int sum = carry;
            if(b1 >= 0)
                sum += bin1[b1--] - '0';
            if(b2 >= 0)
                sum += bin2[b2--] - '0';
            // 2진수 계산
            sb.Append(sum % 2);
            carry = sum / 2;
        }
        // 역으로 붙여 넣었기에 Array.Reverse()로 되돌리기
        char[] answer = sb.ToString().ToCharArray();
        Array.Reverse(answer);
        
        return new string(answer);
    }
}
```

## ⏱️ 복잡도
- 시간: O(N + M) - N은 `bin1` 길이, M은 `bin2` 길이
- 공간: O(N + M) - 결과 문자열 저장
