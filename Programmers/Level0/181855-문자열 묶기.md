# 문자열 묶기
### [Lv.0 - 181855](https://school.programmers.co.kr/learn/courses/30/lessons/181855)

## 문제
문자열 배열 `strArr`이 주어집니다. `strArr`의 원소들을 길이가 같은 문자열들끼리 그룹으로 묶었을 때 가장 개수가 많은 그룹의 크기를 return 하는 solution 함수를 완성해 주세요.
## 풀이
- 같은 문자열들끼리 그룹으로 묶어야 하기에 필요한 문자열의 길이만 List에 담았고 구분을 위해 `Sort()`로오름차순 정렬을 했다.
- 이후 반복문을 통해 다음 원소의 길이와 비교하면서 카운팅했다.

``` C#
using System;
using System.Collections.Generic;

public class Solution {
    public int solution(string[] strArr) {
        int answer = 0;
        int count = 1;
        List<int> strLen = new List<int>();
        
        // 문자열 길이를 List에 넣기
        foreach(string str in strArr)
        {
            strLen.Add(str.Length);
        }
        // 오름차순 정렬
        strLen.Sort();
        
        for(int i = 0; i < strLen.Count-1; i++)
        {
            // 같은 길이가 존재 시 카운트
            if(strLen[i] == strLen[i+1])
            {
                count++;
                // 최대 원소 보유 갱신
                if(answer < count)  answer = count;
            }
            // 같은 길이가 아니면 초기화
            else    count = 1;
                
        }
        
        return answer;
    }
}
```
## 다른 풀이
- Linq로 표현하면 다음과 같이 표현할 수 있다.
- `GroupBy()`로 분류를 한 후 뒤에 `Max()`를 넣어 해당 그룹 중 많이 보이는 걸 추출하고 `Count()`를 통해 세도록 한다. 
```C#
using System;
using System.Linq;

public class Solution {
    public int solution(string[] strArr) =>
        strArr.GroupBy(g=>g.Length).Max(m=>m.Count());
}
```
