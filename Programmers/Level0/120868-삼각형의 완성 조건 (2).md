# 삼각형의 완성 조건 (2)
### [Lv.0 - 120868](https://school.programmers.co.kr/learn/courses/30/lessons/120868)

## 문제
선분 세 개로 삼각형을 만들기 위해서는 다음과 같은 조건을 만족해야 합니다.

가장 긴 변의 길이는 다른 두 변의 길이의 합보다 작아야 합니다.
삼각형의 두 변의 길이가 담긴 배열 `sides`이 매개변수로 주어집니다. 나머지 한 변이 될 수 있는 정수의 개수를 return하도록 solution 함수를 완성해주세요.
## 풀이
- `sides`에서 각각 길이에 따라 분류를 한 후 긴 변이 누구인가에 따른 상황에 맞춰 반복문을 돌렸다.

``` C#
using System;
using System.Linq;

public class Solution {
    public int solution(int[] sides) {
        int answer = 0;
        
        // 주어진 두 변의 최대와 최소 길이 분류
        int sideMax = sides.Max();
        int sideMin = sides.Min();
        
        // 주어진 변들 외의 변이 최대 길이의 변일 때
        for(int i = sideMax+sideMin-1; i > sideMax; i--)
        {
            answer++;
        }
        // 주어진 변들 중 한 변이 최대 길이의 변일 때
        for(int j = sideMax-sideMin; j < sideMax; j++)
        {
            answer++;
        }
        
        
        return answer;
    }
}
```
## 다른 풀이
- 위의 코드는 for문 안에 조건 자체를 삼각형의 완성 조건으로 설정했다면, 아래의 코드는 반복문과 그 안의 조건문으로 이중 점검을 했다.
``` C#
using System;
using System.Linq;
public class Solution {
    public int solution(int[] sides)
        {
            int answer = 0;

            // 주어진 두 변의 최대와 최소 길이 분류
            int max = sides.Max();
            int min = sides.Min();

            // i가 가장 길다는 상황까지 고려
            for (int i = 1; i < max + min; i++)
            {
                // i와 max가 가장 길다는 상황까지 고려
                if (max < i + min)
                {
                    answer++;
                }
            }
            return answer;
        }
}
```
