# [Lv0] 삼각형의 완성 조건 (2)

> **유형:** `#수학` `#구현` `#LINQ`
> **링크:** [120868](https://school.programmers.co.kr/learn/courses/30/lessons/120868)

## 📝 문제 요약
삼각형의 두 변의 길이가 담긴 배열 `sides`가 주어질 때, 나머지 한 변이 될 수 있는 정수의 개수를 return한다. (삼각형 조건: 가장 긴 변의 길이는 다른 두 변의 합보다 작아야 함)

## 💡 접근/풀이 방식
### 1. 범위 분할 반복문
- `sides`에서 최대/최소 길이를 분류한 후, 나머지 한 변이 "최대 길이"인 경우와 "기존 변이 최대"인 경우로 범위를 나눠 반복문을 돌렸다.
### 2. 전체 순회 + 조건문
- 위의 코드는 for문의 범위 자체를 삼각형의 완성 조건으로 설정했다면, 아래의 코드는 반복문과 그 안의 조건문으로 이중 점검을 했다.

## 💻 풀이 코드 (C#)
### 1. 범위 분할 반복문
``` C#
using System;
using System.Linq;

public class Solution {
    public int solution(int[] sides) {
        int answer = 0;
        
        // 주어진 두 변의 최대와 최소 길이 분류
        int sideMax = sides.Max();
        int sideMin = sides.Min();
        
        // 주어진 변들 외의 변이 최대 길이의 변일 때
        for(int i = sideMax+sideMin-1; i > sideMax; i--)
        {
            answer++;
        }
        // 주어진 변들 중 한 변이 최대 길이의 변일 때
        for(int j = sideMax-sideMin; j < sideMax; j++)
        {
            answer++;
        }
        
        
        return answer;
    }
}
```
### 2. 전체 순회 + 조건문
``` C#
using System;
using System.Linq;
public class Solution {
    public int solution(int[] sides)
        {
            int answer = 0;

            // 주어진 두 변의 최대와 최소 길이 분류
            int max = sides.Max();
            int min = sides.Min();

            // i가 가장 길다는 상황까지 고려
            for (int i = 1; i < max + min; i++)
            {
                // i와 max가 가장 길다는 상황까지 고려
                if (max < i + min)
                {
                    answer++;
                }
            }
            return answer;
        }
}
```

## ⏱️ 복잡도
- 시간: O(N) - N은 변의 길이 범위
- 공간: O(1)
