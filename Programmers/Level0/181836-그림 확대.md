# [Lv0] 그림 확대

> **유형:** `#구현`
> **링크:** [181836](https://school.programmers.co.kr/learn/courses/30/lessons/181836)

## 📝 문제 요약
직사각형 형태의 그림 파일이 있고, 이 그림 파일은 1 × 1 크기의 정사각형 크기의 픽셀로 이루어져 있습니다. 
이 그림 파일을 나타낸 문자열 배열 picture과 정수 `k`가 매개변수로 주어질 때, 
이 그림 파일을 가로 세로로 `k`배 늘린 그림 파일을 나타내도록 문자열 배열을 return 하는 solution 함수를 작성해 주세요.

## 💡 접근/풀이 방식
- 받아온 문자열의 한 문자를 `k`배씩 늘리면 된다.
- 한 줄을 완성한 후 세로로도 `k`배 늘려야 확대한 효과가 적용된다.

## 💻 풀이 코드 (C#)

``` C#
using System;
using System.Text;
using System.Collections.Generic;

public class Solution {
    public string[] solution(string[] picture, int k) {
        StringBuilder line = new StringBuilder();
        List<string> answer = new List<string>();
        
        foreach(string linePixel in picture)
        {
            // StringBuilder 내용 지우기
            line.Clear();
            // 가로 내용 확장
            foreach(char pixel in linePixel)
            {
                // k번씩 픽셀 추가
                for(int i = 0; i < k; i++)
                {
                    line.Append(pixel);
                }
            }
            // 가로 줄 완성
            string lineResult = line.ToString();
            
            // k배 만큼 가로의 내용을 세로에 추가
            for(int j = 0; j < k; j++)
            {
                answer.Add(lineResult);
            }
        }
        
        return answer.ToArray();
    }
}
```

## ⏱️ 복잡도
- 시간: O(N × L × K) - N은 `picture` 크기, L은 각 줄 길이, K는 확대 배수
- 공간: O(N × L × K) - 각 줄(N)을 순회하며 각 문자(M)를 K번 복제
