# 수열과 구간 쿼리 4
### [Lv.0 - 181922](https://school.programmers.co.kr/learn/courses/30/lessons/181922)

## 문제
정수 배열 `arr`와 2차원 정수 배열 `queries`이 주어집니다. `queries`의 원소는 각각 하나의 `query`를 나타내며, `[s, e, k]` 꼴입니다.

각 `query`마다 순서대로 `s ≤ i ≤ e`인 모든 `i`에 대해 `i`가 `k`의 배수이면 `arr[i]`에 `1`을 더합니다.

위 규칙에 따라 `queries`를 처리한 이후의 `arr`를 return 하는 solution 함수를 완성해 주세요.
## 풀이
- 문제에서의 `i`는 `queries`의 주어진 범위 내에서만 계산하도록 설정했고 배수의 여부는 나머지 계산에서 0일 경우에만을 적용했다.

``` C#
using System;

public class Solution {
    public int[] solution(int[] arr, int[,] queries) {
        
        for(int i = 0; i < queries.GetLength(0); i++)
        {
            for(int j = queries[i,0]; j <= queries[i,1]; j++)
            {
                if(j%queries[i,2] == 0)
                {
                    arr[j]++;
                }
            }
        }
        
        return arr;
    }
}
```
