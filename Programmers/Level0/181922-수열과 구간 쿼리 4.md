# [Lv0] 수열과 구간 쿼리 4

> **유형:** `#배열` `#구현`
> **링크:** [181922](https://school.programmers.co.kr/learn/courses/30/lessons/181922)

## 📝 문제 요약
정수 배열 `arr`와 2차원 정수 배열 `queries`가 주어집니다. 각 `query`는 `[s, e, k]` 꼴이며, `s ≤ i ≤ e` 범위에서 `i`가 `k`의 배수이면 `arr[i]`에 1을 더합니다. 모든 쿼리를 처리한 후의 `arr`를 반환합니다.

## 💡 접근/풀이 방식
- 문제에서의 `i`는 `queries`의 주어진 범위 내에서만 계산하도록 설정했고 배수의 여부는 나머지 계산에서 0일 경우에만을 적용했다.

## 💻 풀이 코드 (C#)

``` C#
using System;

public class Solution {
    public int[] solution(int[] arr, int[,] queries) {
        
        for(int i = 0; i < queries.GetLength(0); i++)
        {
            for(int j = queries[i,0]; j <= queries[i,1]; j++)
            {
                if(j%queries[i,2] == 0)
                {
                    arr[j]++;
                }
            }
        }
        
        return arr;
    }
}
```

## ⏱️ 복잡도
- 시간: O(Q × N) - Q는 쿼리 수, N은 각 쿼리의 범위
- 공간: O(1) - 기존 `arr`만 갱신
