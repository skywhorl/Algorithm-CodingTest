# 문자열 여러 번 뒤집기
### [Lv.0 - 181913](https://school.programmers.co.kr/learn/courses/30/lessons/181913)

## 문제
문자열 `my_string`과 이차원 정수 배열 `queries`가 매개변수로 주어집니다. `queries`의 원소는 `[s, e]` 형태로, `my_string`의 인덱스 `s`부터 인덱스 `e`까지를 뒤집으라는 의미입니다. 
`my_string`에 `queries`의 명령을 순서대로 처리한 후의 문자열을 return 하는 solution 함수를 작성해 주세요.
## 풀이
- `Array.Reverse(array, start, count)`를 이용하여 주어진 조건 범위 내에서 문자열을 뒤집게 설정했다.

``` C#
using System;

public class Solution {
    public string solution(string my_string, int[,] queries) {
        // 바꾸기 전용 문자 배열
        char[] change = my_string.ToCharArray();
    
        for(int i = 0; i < queries.GetLength(0); i++)
        {
            // 주어진 지점만큼 뒤집기
            Array.Reverse(change, queries[i,0], queries[i,1]-queries[i,0]+1);
        }
        
        // 바뀐 내용 적용
        my_string = new string(change);
        
        return my_string;
    }
}
```
