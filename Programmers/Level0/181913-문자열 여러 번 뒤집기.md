# [Lv0] 문자열 여러 번 뒤집기

> **유형:** `#문자열` `#배열`
> **링크:** [181913](https://school.programmers.co.kr/learn/courses/30/lessons/181913)

## 📝 문제 요약
문자열 `my_string`과 이차원 정수 배열 `queries`가 주어집니다. `queries`의 각 원소 `[s, e]`는 `my_string`의 인덱스 `s`부터 `e`까지 뒤집으라는 의미입니다. 모든 쿼리를 순서대로 처리한 후의 문자열을 반환합니다.

## 💡 접근/풀이 방식
- `Array.Reverse(array, start, count)`를 이용하여 주어진 조건 범위 내에서 문자열을 뒤집게 설정했다.

## 💻 풀이 코드 (C#)

``` C#
using System;

public class Solution {
    public string solution(string my_string, int[,] queries) {
        // 바꾸기 전용 문자 배열
        char[] change = my_string.ToCharArray();
    
        for(int i = 0; i < queries.GetLength(0); i++)
        {
            // 주어진 지점만큼 뒤집기
            Array.Reverse(change, queries[i,0], queries[i,1]-queries[i,0]+1);
        }
        
        // 바뀐 내용 적용
        my_string = new string(change);
        
        return my_string;
    }
}
```

## ⏱️ 복잡도
- 시간: O(Q × L) - 반복문 안에서 L만큼 뒤집는 범위
- 공간: O(N) - `my_string` 길이만큼 char 배열 생성
