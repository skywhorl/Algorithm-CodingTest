# [Lv0] 구슬을 나누는 경우의 수

> **유형:** `#수학` `#구현`
> **링크:** [120840](https://school.programmers.co.kr/learn/courses/30/lessons/120840)

## 📝 문제 요약
머쓱이는 구슬을 친구들에게 나누어주려고 합니다. 구슬은 모두 다르게 생겼습니다.
머쓱이가 갖고 있는 구슬의 개수 `balls`와 친구들에게 나누어 줄 구슬 개수 `share`이 매개변수로 주어질 때,
`balls`개의 구슬 중 `share`개의 구슬을 고르는 가능한 모든 경우의 수를 return 하는 solution 함수를 완성해주세요.

## 💡 접근/풀이 방식
- 서로 다른 `n`개 중 `m`개를 뽑는 경우의 수 공식은 다음과 같다. `n! / (n-m)! x m!`
- 위의 공식 자체를 코드로 적용하면은 팩토리얼 계산 시 엄청난 양의 수가 나올 수 있기에 `n > m`이라는 사실을 통해 `n! / m!`을 미리 계산한 결과를 반복문으로 표현했다.
- **주의**: 풀이에서는 `double`을 사용했지만, 정밀도 오차 위험이 있다. `long`이나 `decimal` 사용이 더 안전하다.

## 💻 풀이 코드 (C#)

``` C#
using System;

public class Solution {
    public int solution(int balls, int share) {
        // 경우의 수 공식
        double answer = Factorial(balls,(share+1)) / Factorial(balls-share);
        return (int)answer;
    }
    
    // 팩토리얼 계산
    private double Factorial(int num, int length = 1) {
        double multiple = 1;
        for(; num >= length; num--)
        {  
            multiple *= num;
        }
        
        return multiple;
    }
}
```

## ⏱️ 복잡도
- 시간: O(N)
- 공간: O(1)
