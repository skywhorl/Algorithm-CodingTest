## 📝 문제 요약
머쓱이는 태어난 지 6개월 된 조카를 돌보고 있습니다. 
조카는 아직 `"aya", "ye", "woo", "ma"` 네 가지 발음을 최대 한 번씩 사용해 조합한(이어 붙인) 발음밖에 하지 못합니다. 
문자열 배열 `babbling`이 매개변수로 주어질 때, 머쓱이의 조카가 발음할 수 있는 단어의 개수를 return하도록 solution 함수를 완성해주세요.

## 💡 접근/풀이 방식
- 찾는 것보단 발견한 걸 대체 가능한 `Replace()` 함수가 있기에 공백으로 변경하여 비교했다.

## 💻 풀이 코드 (C#)

``` C#
using System;

public class Solution {
    public int solution(string[] babbling) {
        int answer = 0;
        
        string[] canSay = {"aya", "ye", "woo", "ma"};
        
        for(int i = 0; i < babbling.Length; i++)
        {
            for(int j = 0; j < canSay.Length; j++)
            {
                // 발음 가능한 단어를 한 단어로 변경
                babbling[i] = babbling[i].Replace(canSay[j], " ");
            }
            // 변경한 단어를 공백으로 변경
            babbling[i] = babbling[i].Replace(" ", "");
            // 변경이 되었다 = 해당 단어의 길이가 0이다
            if(babbling[i].Length == 0)
            {
                answer++;
            }
        }
        
        return answer;
    }
}
```

## ⏱️ 복잡도
- 시간: O(N × M) - N은 `babbling` 크기, M은 각 단어 길이
- 공간: O(M) - `Replace()`로 생성되는 새 문자열
