# [Lv0] 영어가 싫어요

> **유형:** `#문자열` `#배열` `#구현`
> **링크:** [120894](https://school.programmers.co.kr/learn/courses/30/lessons/120894)

## 📝 문제 요약
문자열 `numbers`가 매개변수로 주어질 때, 영어로 표기된 숫자를 수로 바꿔 정수로 return 하도록 solution 함수를 완성해 주세요.

## 💡 접근/풀이 방식
- 한 문자열을 읽어와 여러 문자열과 비교해야 하기에 `string.Equals()`로 비교할 수 없다.
- `string.Replace(string, string)`을 이용하여 자연스럽게 바꿔줬다.

## 💻 풀이 코드 (C#)

``` C#
using System;

public class Solution {
    public long solution(string numbers) {
        // 바꿀 내용들
        string[] changeNum = {"zero", "one", "two", "three", "four", "five", "six", "seven", "eight", "nine"};
        
        for(int i = 0; i < changeNum.Length; i++)
        {
            // 배열의 길이와 숫자가 맞기에 i로 변환
            numbers = numbers.Replace(changeNum[i], i.ToString());
        }
        // 정답 양식
        return long.Parse(numbers);
    }
}
```

## ⏱️ 복잡도
- 시간: O(N) - `Replace()` 10번 (상수) × O(N)
- 공간: O(N) - `Replace()`로 생성되는 새 문자열
