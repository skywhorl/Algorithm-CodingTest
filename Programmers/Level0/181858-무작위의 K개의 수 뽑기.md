# 무작위의 K개의 수 뽑기
### [Lv.0 - 181858](https://school.programmers.co.kr/learn/courses/30/lessons/181858)

## 문제
랜덤으로 서로 다른 `k`개의 수를 저장한 배열을 만드려고 합니다. 
적절한 방법이 떠오르지 않기 때문에 일정한 범위 내에서 무작위로 수를 뽑은 후, 지금까지 나온적이 없는 수이면 배열 맨 뒤에 추가하는 방식으로 만들기로 합니다.

이미 어떤 수가 무작위로 주어질지 알고 있다고 가정하고, 실제 만들어질 길이 `k`의 배열을 예상해봅시다.

정수 배열 `arr`가 주어집니다. 문제에서의 무작위의 수는 `arr`에 저장된 순서대로 주어질 예정이라고 했을 때, 완성될 배열을 return 하는 solution 함수를 완성해 주세요.
단, 완성될 배열의 길이가 `k`보다 작으면 나머지 값을 전부 `-1`로 채워서 return 합니다.
## 풀이
- 배열 초기화로 전부 -1로 설정했는데, `Array.Fill(array, change_number)`를 이용하여 바꾸었다.
- 숫자가 중복인지 확인을 위해 `HashSet`을 이용했다.

``` C#
using System;
using System.Collections.Generic;

public class Solution {
    public int[] solution(int[] arr, int k) {
        int[] answer = new int[k];
        // 빈 자리를 미리 -1로 채우기
        Array.Fill(answer, -1);
        // answer의 원소 위치
        int index = 0;
        
        // 중복 확인을 위한 HashSet
        HashSet<int> check = new HashSet<int>();
        
        foreach(int num in arr)
        {
            // arr의 내용에서 answer로 넣을 때 중복이 아닌 경우 + k의 범위 내일 때
            if(!check.Contains(num) && index < k)
            {
                answer[index] = num;
                index++;
                // 추가 중복 확인을 위한 원소 추가
                check.Add(num);
            }
        }
        
        return answer;
    }
}
```
