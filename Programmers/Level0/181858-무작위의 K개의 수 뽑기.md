# [Lv0] 무작위의 K개의 수 뽑기

> **유형:** `#해시` `#배열`
> **링크:** [181858](https://school.programmers.co.kr/learn/courses/30/lessons/181858)

## 📝 문제 요약
정수 배열 `arr`와 정수 `k`가 주어집니다. `arr`를 앞에서부터 순회하며 지금까지 나온 적 없는 수만 골라 길이 `k`의 배열을 만들어 return 합니다. 길이가 `k`보다 작으면 나머지는 `-1`로 채웁니다.

## 💡 접근/풀이 방식
- 배열 초기화로 전부 -1로 설정했는데, `Array.Fill(array, change_number)`를 이용하여 바꾸었다.
- 숫자가 중복인지 확인을 위해 `HashSet`을 이용했다.

## 💻 풀이 코드 (C#)

``` C#
using System;
using System.Collections.Generic;

public class Solution {
    public int[] solution(int[] arr, int k) {
        int[] answer = new int[k];
        // 빈 자리를 미리 -1로 채우기
        Array.Fill(answer, -1);
        // answer의 원소 위치
        int index = 0;
        
        // 중복 확인을 위한 HashSet
        HashSet<int> check = new HashSet<int>();
        
        foreach(int num in arr)
        {
            // arr의 내용에서 answer로 넣을 때 중복이 아닌 경우 + k의 범위 내일 때
            if(!check.Contains(num) && index < k)
            {
                answer[index] = num;
                index++;
                // 추가 중복 확인을 위한 원소 추가
                check.Add(num);
            }
        }
        
        return answer;
    }
}
```

## ⏱️ 복잡도
- 시간: O(N) - `arr` 전체 순회, `HashSet`의 `Contains`/`Add`는 O(1)
- 공간: O(N)
