# [Lv0] 잘라서 배열로 저장하기

> **유형:** `#배열` `#문자열`
> **링크:** [120913](https://school.programmers.co.kr/learn/courses/30/lessons/120913)

## 📝 문제 요약
문자열 `my_str`과 `n`이 매개변수로 주어질 때, `my_str`을 길이 `n`씩 잘라서 저장한 배열을 return하도록 solution 함수를 완성해주세요.

## 💡 접근/풀이 방식
- 아래의 코드에서는 `n`씩 잘랐을 때 나오게 되는 배열의 길이를 미리 구한 후 각 문자열마다 추가하는 방식으로 작성했다.
- 다른 방식으로는 `List.Add(string.Substring(0, n))`, `string.Remove(0, n)`로 응용할 수 있다.

## 💻 풀이 코드 (C#)

``` C#
using System;

public class Solution {
    public string[] solution(string my_str, int n) {
        // 정답용 배열의 길이 구하기
        int answerLength = my_str.Length / n;
        answerLength += my_str.Length % n == 0 ? 0 : 1;
        string[] answer = new string[answerLength];
        // my_str 용 인덱스
        int index = 0;
        
        for(int i = 0; i < answerLength; i++)
        {
            for(int j = 0; j < n; j++)
            {
                // my_str이 끝날 때까지 n씩 넣기
                if(index < my_str.Length)
                {
                    answer[i] += my_str[index];
                    index++;
                }
            }
        }
        
        return answer;
    }
}
```

## ⏱️ 복잡도
- 시간: O(N × L²) - N은 배열의 길이, L은 `n`, `string +=`가 매번 새 문자열 생성
- 공간: O(N × L) - 결과 배열 N개 × 각 문자열 길이 L, `Substring()` 방식이면 시간도 O(N × L)로 개선
