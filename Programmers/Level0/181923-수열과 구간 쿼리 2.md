# [Lv0] 수열과 구간 쿼리 2

> **유형:** `#정렬` `#배열`
> **링크:** [181923](https://school.programmers.co.kr/learn/courses/30/lessons/181923)

## 📝 문제 요약
정수 배열 `arr`와 2차원 정수 배열 `queries`가 주어집니다. 각 `query`는 `[s, e, k]` 꼴이며, `s ≤ i ≤ e` 범위에서 `k`보다 크면서 가장 작은 `arr[i]`를 찾습니다. 쿼리 순서대로 담은 배열을 반환하며, 조건을 만족하는 값이 없으면 `-1`을 저장합니다.

## 💡 접근/풀이 방식
- 정답용 배열의 빈 칸을 `Array.Fill(array, change_number)`로`0` 대신 미리 `-1`로 채웠다.
- 문제에 제시된 범위 내에서만 반복문을 사용한 후 `List.Sort()`를 이용해 오름차순 정렬 후 가장 작은 값을 추려내도록 했다.

## 💻 풀이 코드 (C#)

``` C#
using System;
using System.Collections.Generic;

public class Solution {
    public int[] solution(int[] arr, int[,] queries) {
        int qLength = queries.GetLength(0);
        
        // 정답용 배열 및 index
        int[] answer = new int[qLength];
        int index = 0;
        // 미리 빈 칸을 -1로 채우기
        Array.Fill(answer, -1);
        
        for(int i = 0; i < qLength; i++)
        {
            // 분류 용 List 생성
            List<int> check = new List<int>();
            // 조건 범위만 탐색
            for(int j = queries[i,0]; j <= queries[i,1]; j++)
            {
                if(arr[j] > queries[i,2])
                {
                    check.Add(arr[j]);
                }
            }
            // 조건에 포함된 원소가 존재 시
            if(check.Count > 0)
            {
                // 오름차순 정렬 후 가장 작은 원소를 추가
                check.Sort();
                answer[index] = check[0];
            }
            index++;
        }
        
        return answer;
    }
}
```

## ⏱️ 복잡도
- 시간: O(Q × N log N) - 각 쿼리마다 범위 탐색 O(N) 후 `Sort()` O(N log N)
- 공간: O(N)
