# 수열과 구간 쿼리 2
### [Lv.0 - 181923](https://school.programmers.co.kr/learn/courses/30/lessons/181923)

## 문제
정수 배열 `arr`와 2차원 정수 배열 `queries`이 주어집니다. `queries`의 원소는 각각 하나의 `query`를 나타내며, `[s, e, k]` 꼴입니다.

각 `query`마다 순서대로 `s ≤ i ≤ e`인 모든 `i`에 대해 k보다 크면서 가장 작은 `arr[i]`를 찾습니다.

각 쿼리의 순서에 맞게 답을 저장한 배열을 반환하는 solution 함수를 완성해 주세요.
단, 특정 쿼리의 답이 존재하지 않으면 `-1`을 저장합니다.
## 풀이
- 정답용 배열의 빈 칸을 `Array.Fill(array, change_number)`로`0` 대신 미리 `-1`로 채웠다.
- 문제에 제시된 범위 내에서만 반복문을 사용한 후 `List.Sort()`를 이용해 오름차순 정렬 후 가장 작은 값을 추려내도록 했다.

``` C#
using System;
using System.Collections.Generic;

public class Solution {
    public int[] solution(int[] arr, int[,] queries) {
        int qLength = queries.GetLength(0);
        
        // 정답용 배열 및 index
        int[] answer = new int[qLength];
        int index = 0;
        // 미리 빈 칸을 -1로 채우기
        Array.Fill(answer, -1);
        
        for(int i = 0; i < qLength; i++)
        {
            // 분류 용 List 생성
            List<int> check = new List<int>();
            // 조건 범위만 탐색
            for(int j = queries[i,0]; j <= queries[i,1]; j++)
            {
                if(arr[j] > queries[i,2])
                {
                    check.Add(arr[j]);
                }
            }
            // 조건에 포함된 원소가 존재 시
            if(check.Count > 0)
            {
                // 오름차순 정렬 후 가장 작은 원소를 추가
                check.Sort();
                answer[index] = check[0];
            }
            index++;
        }
        
        return answer;
    }
}
```
