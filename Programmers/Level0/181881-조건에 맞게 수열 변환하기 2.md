# 조건에 맞게 수열 변환하기 2
### [Lv.0 - 181881](https://school.programmers.co.kr/learn/courses/30/lessons/181881)

## 문제
정수 배열 `arr`가 주어집니다. 
`arr`의 각 원소에 대해 값이 50보다 크거나 같은 짝수라면 2로 나누고, 50보다 작은 홀수라면 2를 곱하고 다시 1을 더합니다.

이러한 작업을 `x`번 반복한 결과인 배열을 `arr(x)`라고 표현했을 때, `arr(x) = arr(x + 1)`인 `x`가 항상 존재합니다. 이러한 `x` 중 가장 작은 값을 return 하는 solution 함수를 완성해 주세요.

단, 두 배열에 대한 `"="`는 두 배열의 크기가 서로 같으며, 같은 인덱스의 원소가 각각 서로 같음을 의미합니다.
## 풀이
- `arr(x) = arr(x + 1)`을 표현하려면 이전에 존재한 배열과 비교를 해야 하는데, 여기서 `int[] preArr = arr`이라고 작성하면 안 된다.
- 위의 방식은 주솟값을 공유하는 것이기에 값이 변경되어 항상 같게 되는 상황이 발생하기에 `Clone()`나 `Array.Copy()`를 사용해야 한다.

``` C#
using System;

public class Solution {
    public int solution(int[] arr) {
        int answer = 0;
        
        while(true)
        {
            // 이전 배열 복제 및 비교용
            int[] preArr = (int[])arr.Clone();
            
            // 규칙에 맞게 조건 변형
            for(int i = 0; i < arr.Length; i++)
            {
                if(arr[i] >= 50 && arr[i] % 2 == 0) 
                {
                    arr[i] /= 2;
                }
                else if(arr[i] < 50 && arr[i] % 2 != 0) 
                {
                    arr[i] = (arr[i] * 2) + 1;
                }
            }
            
            // 이전 배열과 비교
            if(ArrayEqual(preArr, arr))
                return answer;
            
            // arr(x) = arr(x + 1) 이 아니므로 반복 카운트 갱신
            answer++;   
        }
        
        return answer;
    }
    
    // 두 배열의 값이 전부 일치하는지 확인
    private bool ArrayEqual(int[] a, int[] b)
    {
        for(int i = 0; i < a.Length; i++) 
        {
            // 하나라도 틀리면 false를 return
            if(a[i] != b[i])
            {
                return false;
            }
        }
        return true;
    }
}
```
