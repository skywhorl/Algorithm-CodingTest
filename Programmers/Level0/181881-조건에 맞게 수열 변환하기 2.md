# [Lv0] 조건에 맞게 수열 변환하기 2

> **유형:** `#시뮬레이션` `#배열`
> **링크:** [181881](https://school.programmers.co.kr/learn/courses/30/lessons/181881)

## 📝 문제 요약
정수 배열 `arr`의 각 원소에 대해 (50 이상 짝수면 2로 나누기, 50 미만 홀수면 2를 곱하고 1을 더하기) 변환을 반복 적용합니다. 변환 결과가 직전과 같아지는(더 이상 바뀌지 않는) 최소 반복 횟수 `x`를 return 합니다.

## 💡 접근/풀이 방식
- `arr(x) = arr(x + 1)`을 표현하려면 이전에 존재한 배열과 비교를 해야 하는데, 여기서 `int[] preArr = arr`이라고 작성하면 안 된다.
- 위의 방식은 주솟값을 공유하는 것이기에 값이 변경되어 항상 같게 되는 상황이 발생하기에 `Clone()`나 `Array.Copy()`를 사용해야 한다.

## 💻 풀이 코드 (C#)

``` C#
using System;

public class Solution {
    public int solution(int[] arr) {
        int answer = 0;
        
        while(true)
        {
            // 이전 배열 복제 및 비교용
            int[] preArr = (int[])arr.Clone();
            
            // 규칙에 맞게 조건 변형
            for(int i = 0; i < arr.Length; i++)
            {
                if(arr[i] >= 50 && arr[i] % 2 == 0) 
                {
                    arr[i] /= 2;
                }
                else if(arr[i] < 50 && arr[i] % 2 != 0) 
                {
                    arr[i] = (arr[i] * 2) + 1;
                }
            }
            
            // 이전 배열과 비교
            if(ArrayEqual(preArr, arr))
                return answer;
            
            // arr(x) = arr(x + 1) 이 아니므로 반복 카운트 갱신
            answer++;   
        }
        
        return answer;
    }
    
    // 두 배열의 값이 전부 일치하는지 확인
    private bool ArrayEqual(int[] a, int[] b)
    {
        for(int i = 0; i < a.Length; i++) 
        {
            // 하나라도 틀리면 false를 return
            if(a[i] != b[i])
            {
                return false;
            }
        }
        return true;
    }
}
```

## ⏱️ 복잡도
- 시간: O(N × M) - M은 반복 횟수, 각 반복마다 Clone/변환/비교가 O(N)
- 공간: O(N) - `preArr`로 `arr`를 복제
