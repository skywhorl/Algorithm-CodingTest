# [Lv0] 배열 만들기 6

> **유형:** `#스택` `#배열`
> **링크:** [181859](https://school.programmers.co.kr/learn/courses/30/lessons/181859)

## 📝 문제 요약
0과 1로 이루어진 정수 배열 `arr`가 주어집니다. `arr`를 순회하며 `stk`을 다음과 같이 만들어 return 합니다.
- `stk`이 비었으면 `arr[i]`를 push
- `stk`의 마지막 원소가 `arr[i]`와 같으면 pop
- 다르면 `arr[i]`를 push

단, 빈 배열이 되는 경우 `[-1]`을 return 합니다.

## 💡 접근/풀이 방식
- 문제에서 제시한 조건들을 차근히 코드로 표현하면 풀 수 있는 문제로 원소를 제거할 때 해당 위치의 원소를 지워주는`List.RemoveAt(index)`를 사용했다.
- 참고로, `List.Remove(element)`는 해당 위치가 아닌 해당 값을 가진 원소를 제거하는 것이다.

## 💻 풀이 코드 (C#)

``` C#
using System;
using System.Collections.Generic;

public class Solution {
    public int[] solution(int[] arr) {
        List<int> stk = new List<int>();
        
        for(int i = 0; i < arr.Length; i++)
        {
            // 문제 1번째 조건
            if(stk.Count == 0)  stk.Add(arr[i]);
            else
            {
                // 문제 2번째 조건
                if(stk[stk.Count - 1] == arr[i]) stk.RemoveAt(stk.Count - 1);
                // 문제 3번째 조건
                else stk.Add(arr[i]);
            }
        }
        
        // 빈 배열이면 [-1] return 하기
        return stk.Count == 0 ? new int[]{-1} : stk.ToArray();
    }
}
```

## ⏱️ 복잡도
- 시간: O(N) - `arr` 한 번 순회, 리스트 끝에서의 `Add`/`RemoveAt`은 O(1)
- 공간: O(N)
