# [Lv0] 왼쪽 오른쪽

> **유형:** `#배열` `#구현`
> **링크:** [181890](https://school.programmers.co.kr/learn/courses/30/lessons/181890)

## 📝 문제 요약
문자열 리스트 `str_list`에서 `"l"`과 `"r"` 중 먼저 나오는 문자열이 `"l"`이라면 그 왼쪽 부분을, `"r"`이라면 그 오른쪽 부분을 순서대로 담은 리스트를 반환합니다. 둘 다 없다면 빈 리스트를 반환합니다.

## 💡 접근/풀이 방식
- 먼저 나온 문자열을 기준으로 새로 문자열 리스트 길이를 정한다.
- `Array.Copy(원본, 원본 복사 시작 위치, 복사 대상, 대상 붙여넣기 시작 위치, 시작 위치부터 붙여넣을 길이)`를 이용하여 배열의 값을 범위에 맞게 복사한다.

## 💻 풀이 코드 (C#)

``` C#
using System;

public class Solution {
    public string[] solution(string[] str_list) {
        for (int i = 0; i < str_list.Length; i++) {
            // l이 먼저 나오면
            if (str_list[i] == "l") {
                string[] answer = new string[i];
                Array.Copy(str_list, 0, answer, 0, i);
                return answer;
            }
            // r이 먼저 나오면
            if (str_list[i] == "r") {
                int length = str_list.Length - (i + 1);
                string[] answer = new string[length];
                Array.Copy(str_list, i + 1, answer, 0, length);
                return answer;
            }
        }
        return new string[0];
    }
}
```

## ⏱️ 복잡도
- 시간: O(N) - 배열을 앞에서 순회, `Array.Copy()`는 선형
- 공간: O(N)
