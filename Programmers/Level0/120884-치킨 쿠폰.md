# [Lv0] 치킨 쿠폰

> **유형:** `#수학` `#구현`
> **링크:** [120884](https://school.programmers.co.kr/learn/courses/30/lessons/120884)

## 📝 문제 요약
치킨 한 마리당 쿠폰 한 장이 발급되고, 쿠폰 10장으로 서비스 치킨 1마리를 받을 수 있다(서비스 치킨에도 쿠폰 발급). 시켜먹은 치킨 수 `chicken`이 주어질 때 받을 수 있는 최대 서비스 치킨 수를 return한다.

## 💡 접근/풀이 방식
- `쿠폰의 개수 = 주문한 치킨의 수`이기에 따로 쿠폰의 변수는 만들지 않았다.
- 서비스로 주문하고서 남은 쿠폰들이 10 미만이어야 하기에 반복문으로 10 이상을 설정하고 계속해서 10으로 나눠주게 해야한다.

## 💻 풀이 코드 (C#)

``` C#
using System;

public class Solution {
    public int solution(int chicken) {
        int service = 0;
        
        // 쿠폰 개수 = 치킨 주문 수
        while(chicken >= 10)
        {
            // 서비스 계산
            service += chicken / 10;
            // 남은 쿠폰(치킨) 정산
            chicken = (chicken / 10) + (chicken % 10);
        }
        
        return service;
    }
}
```

## ⏱️ 복잡도
- 시간: O(log N) - 반복문에서 `chicken`의 수가 줄어듦
- 공간: O(1)
