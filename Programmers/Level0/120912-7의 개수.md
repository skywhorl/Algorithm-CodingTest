# [Lv0] 7의 개수

> **유형:** `#배열` `#구현` `#LINQ`
> **링크:** [120912](https://school.programmers.co.kr/learn/courses/30/lessons/120912)

## 📝 문제 요약
정수 배열 `array`가 매개변수로 주어질 때, 7이 총 몇 개 있는지 return 하도록 solution 함수를 완성해보세요.

## 💡 접근/풀이 방식
### 1. Replace 길이 차이
- 7을 공백으로 변환하여 기존의 길이와 비교하게 되면 해당 길이의 차수만큼 7의 개수를 확인할 수 있다.
### 2. LINQ Concat + Count
- 이어 붙이는 기능인 `Concat()`를 사용해 string 타입으로 이어 붙이고 거기서 7을 포함하는지 `Count()`로 센다.

## 💻 풀이 코드 (C#)
### 1. Replace 길이 차이
``` C#
using System;

public class Solution {
    public int solution(int[] array) {
        int answer = 0;
        foreach(int num in array)
        {
            string str = num.ToString();
            answer += str.Length - str.Replace("7", "").Length;
        }
        return answer;
    }
}
```
### 2. LINQ Concat + Count 활용
``` C#
using System.Linq;

public class Solution {
    public int solution(int[] array) =>
        string.Concat(array).Count(x => x == '7');
}
```

## ⏱️ 복잡도
- 시간: O(N)
- 공간: O(N) - `Replace()`, `Concat()`
