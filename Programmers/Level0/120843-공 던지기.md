# 공 던지기
### [Lv.0 - 120843](https://school.programmers.co.kr/learn/courses/30/lessons/120843)

## 문제
머쓱이는 친구들과 동그랗게 서서 공 던지기 게임을 하고 있습니다. 
공은 1번부터 던지며 오른쪽으로 한 명을 건너뛰고 그다음 사람에게만 던질 수 있습니다. 
친구들의 번호가 들어있는 정수 배열 `numbers`와 정수 `K`가 주어질 때, `k`번째로 공을 던지는 사람의 번호는 무엇인지 return 하도록 solution 함수를 완성해보세요.
## 풀이
- 몇 번째든 0번째부터 시작하기에 `k-1`로 인덱스를 맞춘다.
- 2번씩 넘어가기에 2를 곱한다.
- `number.Length`를 기준으로 넘어가기에 나머지 연산을 하면 넘겨야 하는 위치가 뜬다.

``` C#
using System;

public class Solution {
    public int solution(int[] numbers, int k) {
        return numbers[((k-1)*2) % numbers.Length];
    }
}
```
