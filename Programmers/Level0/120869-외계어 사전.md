# [Lv0] 외계어 사전

> **유형:** `#배열` `#구현` `#문자열`
> **링크:** [120869](https://school.programmers.co.kr/learn/courses/30/lessons/120869)

## 📝 문제 요약
알파벳이 담긴 배열 `spell`과 외계어 사전 `dic`이 매개변수로 주어질 때, `spell`에 담긴 알파벳을 한번씩만 모두 사용한 단어가 `dic`에 존재한다면 `1`, 존재하지 않는다면 `2`를 return한다.

## 💡 접근/풀이 방식
- `spell의 원소의 수 = dic의 한 원소의 문자열 길이`이기에 `Contains()`로 포함할 때마다 길이로 비교한 카운트를 추가했다.

## 💻 풀이 코드 (C#)

``` C#
using System;

public class Solution {
    public int solution(string[] spell, string[] dic) {
        int answer = 2;
        
        for(int i = 0; i < dic.Length; i++)
        {
            // 문자 일치 확인 변수
            int check = 0;
            for(int j = 0; j < spell.Length; j++)
            {
                // spell의 내용이 dic에 포함될 때
                if(dic[i].Contains(spell[j]))
                {
                    // 카운트 추가
                    check++;
                }
            }
            // 해당 카운트가 spell 길이랑 같으면 모든 spell이 들어간 dic
            if(check == spell.Length)
                {
                    answer = 1;
                    break;
                }
        }
        
        return answer;
    }
}
```

## ⏱️ 복잡도
- 시간: O(N × M) - N은 dic 크기, M은 spell 크기 (단어 길이는 상수로 가정)
- 공간: O(1)
