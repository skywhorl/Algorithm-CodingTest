# [Lv0] 컨트롤 제트

> **유형:** `#문자열` `#LINQ` `#스택` 
> **링크:** [120853](https://school.programmers.co.kr/learn/courses/30/lessons/120853)

## 📝 문제 요약
숫자와 "Z"가 공백으로 구분되어 담긴 문자열이 주어집니다.
문자열에 있는 숫자를 차례대로 더하려고 합니다. 이 때 "Z"가 나오면 바로 전에 더했던 숫자를 뺀다는 뜻입니다.
숫자와 "Z"로 이루어진 문자열 `s`가 주어질 때, 머쓱이가 구한 값을 return 하도록 solution 함수를 완성해보세요.
("Z"가 연속해서 나오는 경우는 없습니다.)

## 💡 접근/풀이 방식
### 1. TryParse 순회
- 제한사항에서 "Z"는 연속하지 않기에 해당 사항을 고려하지 않은 코드를 작성했다, string으로 저장한 `s`의 원소들을 int로 형변환이 가능한지 여부에 따라 계산을 진행했다.
### 2. LINQ Aggregate + Stack 활용
- `Aggregate()`는 `Sum()`과 다르게 규칙을 정해 결과값을 누적(합산)해주는 함수다.
- "Z"가 보일 경우 이전의 값을 빼는 것이기에 `Pop()`으로 최근 원소를 빼주고 이외에는 `Push()`로 집어넣는다

## 💻 풀이 코드 (C#)
### 1. TryParse 순회
``` C#
using System;

public class Solution {
    public int solution(string s) {
        int answer = 0;
        // 공백 단위로 나누기
        string[] cal = s.Split(' ');
        
        for(int i = 0; i < cal.Length; i++)
        {
            var num = 0;
            // 정수로 형변환이 되면 합산, 아니면 Z이기에 뒤의 원소 빼기
            if(int.TryParse(cal[i], out num))
            {
                answer += num;
            }
            else
            {
                answer -= int.Parse(cal[i-1]);
            }
        }

        return answer;
    }
}
```
### 2. LINQ Aggregate + Stack 활용
``` C#
using System;
using System.Linq;
using System.Collections.Generic;

public class Solution {
    public int solution(string s) =>
        s.Split(' ').Aggregate(new Stack<int>(), (stack, cur) => {
            if (cur == "Z") stack.Pop();
            else stack.Push(int.Parse(cur));
            return stack;
        }).Sum();
}
```

## ⏱️ 복잡도
- 시간: O(N)
- 공간: O(N) - 풀이 1은 Split 배열, 풀이 2는 Stack
