# [Lv2] 점프와 순간 이동

> **유형:** `#그리디`
> **링크:** [12980](https://school.programmers.co.kr/learn/courses/30/lessons/12980)

## 📝 문제 요약
OO 연구소는 한 번에 K 칸을 앞으로 점프하거나, (현재까지 온 거리) x 2 에 해당하는 위치로 순간이동을 할 수 있는 특수한 기능을 가진 아이언 슈트를 개발하여 판매하고 있습니다. 이 아이언 슈트는 건전지로 작동되는데, 순간이동을 하면 건전지 사용량이 줄지 않지만, 앞으로 K 칸을 점프하면 K 만큼의 건전지 사용량이 듭니다.
이동하려는 거리 `N`이 주어졌을 때, 사용해야 하는 건전지 사용량의 최솟값을 return하는 solution 함수를 만들어 주세요.

## 💡 접근/풀이 방식
- 문제에서 가장 배터리를 적게 쓰려면 무조건 한 칸 이동 후 가능한 순간 이동을 계속하면 된다.
- 순간이동은 이동한 만큼의 2배로 이동하므로 이동하고서 남은 점프 거리는 `N`을 2로 나누었을 때 생기는 나머지의 누적을 구하면 된다.

## 💻 풀이 코드 (C#)

```C#
using System;

class Solution
{
    public int solution(int n)
    {
        // 소모된 배터리 개수
        // 한 번 이동하고 전부 순간 이동이 최적화라 1로 저장
        int battery = 1;
        
        while(n >= 2)
        {
            // 2로 나누었을 때 나머지가 발생하면 이후에 점프해야 하기에 배터리로 간주
            battery += n % 2;
            // 순간이동 
            n /= 2;
        }

        return battery;
    }
}
```

## ⏱️ 복잡도
- 시간: O(log N) - N이 매 반복마다 절반으로 줄어 log₂(N)번 반복
- 공간: O(1)
