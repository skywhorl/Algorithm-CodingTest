# [Lv2] 혼자서 하는 틱택토

> **유형:** `#구현`
> **링크:** [160585](https://school.programmers.co.kr/learn/courses/30/lessons/160585)

## 📝 문제 요약
머쓱이가 혼자서 게임을 진행하다 의문이 생긴 틱택토 게임판의 정보를 담고 있는 문자열 배열 `board`가 매개변수로 주어질 때, 이 게임판이 규칙을 지켜서 틱택토를 진행했을 때 나올 수 있는 게임 상황이면 `1`을 아니라면 `0`을 return 하는 solution 함수를 작성해 주세요.

## 💡 접근/풀이 방식
- 틱택토 규칙 상 3X3 보드가 고정이기에 단순 이중 반복문으로 각각의 O, X를 카운트 했다.
- 이후 O와 X의 개수를 세어 개수 기준으로 규칙에 맞지 않는 승부를 제외했고, 판정이 필요한 경우 `CanWin()`이라는 메서드를 통해 가로/세로/대각선에 배치된 내용들을 검사했다.

## 💻 풀이 코드 (C#)

```C#
using System;

public class Solution {
    public int solution(string[] board) {
  
        // O X 개수 구하는 용도
        int oCount = 0;
        int xCount = 0;
        
        // 틱택토 시작
        for(int i = 0; i < 3; i++)
        {
            for(int j = 0; j < 3; j++)
            {
                // 각각의 O, X 개수 세기
                if(board[i][j] == 'O') oCount++;
                else if(board[i][j] == 'X') xCount++;
            }
        }
        
        // O와 X의 개수 자체가 게임의 규칙에 맞지 않을 경우 제외
        if(oCount < xCount || oCount > xCount + 1) return 0;
        
        // 게임에서 O가 이겼는데 개수가 이상할 경우(X가 다음에 또 뒀나거나)
        if(oCount == xCount && CanWin(board, 'O')) return 0;
            
        // 게임에서 X가 이겼는데 개수가 이상할 경우(O가 다음에 또 뒀나거나)
        if(oCount == xCount + 1 && CanWin(board, 'X')) return 0;
        
        // 게임이 이상한 경우를 모두 제거함
        return 1;
    }
    
    // 해당 게임이 이길 수 있는 건지 확인
    private bool CanWin(string[] board, char c) {
        // 가로 세로 검사
        for(int i = 0; i < 3; i++)
        {
            if (board[i][0] == c && board[i][1] == c && board[i][2] == c) return true;
            else if (board[0][i] == c && board[1][i] == c && board[2][i] == c) return true;
        }
        
        // 대각선 검사
        if (board[0][0] == c && board[1][1] == c && board[2][2] == c) return true;
        if (board[0][2] == c && board[1][1] == c && board[2][0] == c) return true; 
        
        return false;
    }
}
```

## ⏱️ 복잡도
- 시간: O(1) - 3×3 보드 고정, 모든 검사가 상수 횟수
- 공간: O(1)
