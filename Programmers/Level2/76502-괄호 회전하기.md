# [Lv2] 괄호 회전하기

> **유형:** `#스택` `#문자열`
> **링크:** [76502](https://school.programmers.co.kr/learn/courses/30/lessons/76502)

## 📝 문제 요약
대괄호, 중괄호, 그리고 소괄호로 이루어진 문자열 `s`가 매개변수로 주어집니다. 이 `s`를 왼쪽으로 `x (0 ≤ x < (s의 길이))` 칸만큼 회전시켰을 때 `s`가 올바른 괄호 문자열이 되게 하는 `x`의 개수를 return 하도록 solution 함수를 완성해주세요.

## 💡 접근/풀이 방식
- 문자열 길이가 홀수면 괄호 짝이 안 맞으므로 즉시 0으로 반환한다.
- 회전된 문자열을 만들 때는 `Substring()`으로 앞뒤를 잘라 이어 붙이는 방식으로 처리했다.
- `Stack`을 통해 여는 괄호는 `Push()`, 닫는 괄호가 나오면 스택 top과 짝 비교 후 `Pop()`으로 처리했다.
  - 스택이 비었는데 닫는 괄호가 나오면 `false`(열린 괄호 없이 닫음).
  - 마지막에 스택이 비어있어야 모든 짝이 맞는 것이다.

## 💻 풀이 코드 (C#)

```C#
using System;
using System.Collections.Generic;

public class Solution {
    public int solution(string s) {
        int answer = 0;
        int length = s.Length;
        
        // 문자열 길이가 홀수면 괄호가 누락된 상태
        if(s.Length % 2 != 0)
            return 0;

        for(int i = 0; i < length; i++) 
        {
            // 순서 바꾸기
            string rotated = s.Substring(i) + s.Substring(0, i);
            
            // 회전된 문자열이 올바른 괄호인지 검사
            if(IsRight(rotated)) 
                answer++;
        }
        
        return answer;
    }
    
    
    // 올바른 괄호 문자열인지 확인하는 메서드
    private bool IsRight(string s) {
        Stack<char> stack = new Stack<char>();

        foreach (char c in s) 
        {
            // 여는 괄호는 스택에 밀어 넣기
            if (c == '(' || c == '{' || c == '[') 
            {
                stack.Push(c);
            }
            // 닫는 괄호일 경우
            else 
            {
                // 열린 괄호가 없는데 닫으려 하면 즉시 실패
                if (stack.Count == 0) return false;

                // 스택 맨 위에 있는 여는 괄호를 꺼냄
                char top = stack.Pop();

                // 짝이 맞는지 하나씩 검사
                if(c == ')' && top != '(') return false;
                if(c == '}' && top != '{') return false;
                if(c == ']' && top != '[') return false;
            }
        }
        // 루프가 끝난 뒤, 스택이 비어있어야 모든 짝이 완벽히 맞음
        return stack.Count == 0;
    }
}
```

## ⏱️ 복잡도
- 시간: O(N^2) - N가지 회전 × 각 회전마다 O(N) 검증
- 공간: O(N) - 회전된 문자열과 스택
