# [Lv2] 기능개발

> **유형:** `#구현`
> **링크:** [42586](https://school.programmers.co.kr/learn/courses/30/lessons/42586)

## 📝 문제 요약
먼저 배포되어야 하는 순서대로 작업의 진도가 적힌 정수 배열 `progresses`와 각 작업의 개발 속도가 적힌 정수 배열 `speeds`가 주어질 때 각 배포마다 몇 개의 기능이 배포되는지를 return 하도록 solution 함수를 완성하세요.

## 💡 접근/풀이 방식
- 배포의 조건은 무조건 진행도가 100 이상이어야 하기에 작업 일수를 올림처리 해야 한다.
- 앞에 있는 작업부터 순서대로 배포해야 하므로, 현재 그룹의 가장 오래 걸리는 작업 일수를 기준으로 잡고, 그보다 같거나 빨리 끝나는 뒤 작업들은 함께 배포된다.

## 💻 풀이 코드 (C#)

```C#
using System;
using System.Collections.Generic;

public class Solution {
    public int[] solution(int[] progresses, int[] speeds) {
        // 경우에 따라 크기가 변하기에 List 사용
        List<int> answer = new List<int>();
        
        int length = progresses.Length;
        int[] finishDays = new int[length];
        
        for(int i = 0; i < length; i++)
        {
            // 완벽히 완성되는 날을 위한 작업 일수 올림 처리
            finishDays[i] = (int)Math.Ceiling((double)(100 - progresses[i]) / speeds[i]);
        }
        
        // 가장 오래 걸린 작업 일수
        int max = finishDays[0];
        // 같이 배포하는 수
        int count = 1;
        
        for(int i = 1; i < length; i++)
        {
            // 앞의 최대 작업일 보다 적으면 같이 배포
            if(finishDays[i] <= max)
                count++;
            // 더 많으면 정답 등록 및 갱신
            else
            {
                answer.Add(count);
                max = finishDays[i];
                count = 1;
            }
        }
        
        // 순회 후 마지막 배포 카운트 추가
        answer.Add(count);
        
        return answer.ToArray();
    }
}
```

## ⏱️ 복잡도
- 시간: O(N) - N = `progresses.Length` 또는 `speeds.Length`
- 공간: O(N)
