# [Lv2] 예상 대진표

> **유형:** `#구현`
> **링크:** [12985](https://school.programmers.co.kr/learn/courses/30/lessons/12985)

## 📝 문제 요약
게임 참가자 수 `N`, 참가자 번호 `A`, 경쟁자 번호 `B`가 함수 solution의 매개변수로 주어질 때, 처음 라운드에서 `A`번을 가진 참가자는 경쟁자로 생각하는 `B`번 참가자와 몇 번째 라운드에서 만나는지 return 하는 solution 함수를 완성해 주세요. 단, `A`번 참가자와 `B`번 참가자는 서로 붙게 되기 전까지 항상 이긴다고 가정합니다.

## 💡 접근/풀이 방식
- 각자 대진 하고서 다음에 받게 되는 대진 번호는 2로 나누었을 때 각각 몫과 나머지를 합한 값이다.
- 위의 방식을 이용하여 `A`와 `B`가 만나는 순간은 while문에서 설정한 것처럼 두 수가 같아지는 경우다.
- 풀이에서 1을 더해준 이유는 `A`나 `B`중 대진 번호를 1로 받게 되면 2로 나누었을 때 몫이 0이 되기 때문이다.

## 💻 풀이 코드 (C#)

```C#
using System;

class Solution
{
    public int solution(int n, int a, int b)
    {
        int answer = 0;

        while(a != b)
        {
            // 대진시작 
            answer++;

            // 다음 대진 번호 발급
            a = (a+1) / 2;
            b = (b+1) / 2;
        }

        return answer;
    }
}
```

## ⏱️ 복잡도
- 시간: O(log N) - 매 경기마다 대진이 절반씩 줄어듦
- 공간: O(1)
