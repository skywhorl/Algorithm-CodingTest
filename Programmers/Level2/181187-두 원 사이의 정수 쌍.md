# [Lv2] 두 원 사이의 정수 쌍

> **유형:** `#구현`
> **링크:** [181187](https://school.programmers.co.kr/learn/courses/30/lessons/181187)

## 📝 문제 요약
x축과 y축으로 이루어진 2차원 직교 좌표계에 중심이 원점인 서로 다른 크기의 원이 두 개 주어집니다. 반지름을 나타내는 두 정수 `r1`, `r2`가 매개변수로 주어질 때, 두 원 사이의 공간에 x좌표와 y좌표가 모두 정수인 점의 개수를 return하도록 solution 함수를 완성해주세요.

## 💡 접근/풀이 방식
- 동심원의 중심을 좌표 상 원점으로 두기에 제1사분면에서의 점의 개수를 구한 후 4를 곱해도 된다.
- X축을 기준으로 `r2`까지 이동했을 때 두 원에서 가지는 Y좌표는 각각 큰 원은 내림, 작은 원은 올림으로 표현해야 정수 범위에 들어온다.

## 💻 풀이 코드 (C#)

```C#
using System;

public class Solution {
    public long solution(int r1, int r2) {
        long answer = 0;
        // X를 1부터 큰 원의 반지름(r2)까지 1씩 이동하며 기둥을 세운다.
        for (long x = 1; x <= r2; x++) 
        {
            // 현재 X에서 큰 원의 반지름만큼 빼면 해당 X좌표의 Y좌표 최댓값, 범위 안에 들어와야 하고 정수 변환을 위해 내림
            long max = (long)Math.Floor(Math.Sqrt((long)r2 * r2 - x * x));

            // 기본 바닥은 X축(0)
            long min = 0; 
            // 범위 계산에서 Y의 최솟값을 구하려면 작은 원 범위 안에 들어가야 함
            if (x < r1) 
            {
                // 현재 X에서 작은 원의 반지름만큼 빼면 해당 X좌표의 Y좌표 최솟값, 범위 안에 들어와야 하고 정수 변환을 위해 올림
                min = (long)Math.Ceiling(Math.Sqrt((long)r1 * r1 - x * x));
            }

            // X 좌표에 있는 정수 점의 개수를 더하기
            answer += (max - min + 1);
        }

        // 제1사분면만 구했기에 4 곱하기
        return answer * 4;
    }
}
```

## ⏱️ 복잡도
- 시간: O(N) - N: `r2`, X좌표가 N까지 순회
- 공간: O(1)
