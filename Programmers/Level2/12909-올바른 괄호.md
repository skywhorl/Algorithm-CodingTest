# [Lv2] 올바른 괄호

> **유형:** `#문자열` `#구현` 
> **링크:** [12909](https://school.programmers.co.kr/learn/courses/30/lessons/12909)

## 📝 문제 요약
'(' 또는 ')' 로만 이루어진 문자열 `s`가 주어졌을 때, 문자열 `s`가 올바른 괄호이면 `true`를 return 하고, 올바르지 않은 괄호이면 `false`를 return 하는 solution 함수를 완성해 주세요.
## 💡 접근/풀이 방식
- 괄호는 `(`로 무조건 시작해야 하므로 첫 글자가 `)`면 즉시 `false`로 반환한다.
- 쌍을 추적하기 위해 `(`를 +1, `)`를 -1로 카운트하며 순회한다.
- 순회 도중 카운트가 음수가 되면 짝지을 여는 괄호가 없다는 뜻이므로 `false`다.
- 마지막에 카운트가 0이면 모든 괄호가 짝을 이룬 것이기에 `true`다.

## 💻 풀이 코드 (C#)

```C#
using System;

public class Solution {
    public bool solution(string s) {
        // 시작부터 마치는 괄호면 아예 틀린 거
        if(s[0] == ')') return false;
        
        int count = 0;
    
        foreach(char c in s)
        {
            // 각 괄호마다 카운드 조절
            if(c == '(') count++;
            else count--;
            
            // 닫는 괄호가 더 많다는 건 ()를 만들 수 없음
            if(count < 0) return false;
        }
        
        // 쌍으로 있을 때만 참
        return count == 0;
    }
}
```

## ⏱️ 복잡도
- 시간: O(N)
- 공간: O(1)
