# [Lv2] N개의 최소공배수

> **유형:** `#수학` `##유클리드호제법`
> **링크:** [12953](https://school.programmers.co.kr/learn/courses/30/lessons/12953)

## 📝 문제 요약
n개의 숫자를 담은 배열 arr이 입력되었을 때 이 수들의 최소공배수를 반환하는 함수, solution을 완성해 주세요.

## 💡 접근/풀이 방식
- 두 수의 최소공배수를 구하려면 두 수의 최대공약수를 구한 후 두 수의 곱에서 나누면 된다.
- N개의 최소공배수는 결합법칙 성립으로 두 수의 최소공배수를 구한 후 그 수와 다음 수끼리 계산하면 된다.
- 계산 최적화를 위해 최대공약수는 재귀함수가 아닌 유클리드 호제법을, 최소공배수를 구할 땐 오버플로우 방지를 위해 곱셈을 후반에 배치했다.

## 💻 풀이 코드 (C#)

```C#
public class Solution {
    public int solution(int[] arr) { 
        // 종합 최소공배수(맨 처음 수를 최소공배수로 초기화)
        int lcm = arr[0];
        
        for(int i = 1; i < arr.Length; i++)
            lcm = GetLCM(lcm, arr[i]);
        
        return lcm;
    }
    
    // 최소 공배수 구하기, 반환은 오버플로우 방지 계산
    private int GetLCM(int a, int b) {
        return (a/GetGCD(a, b))*b;
    }
    
    // 최대 공약수 구하기
    private int GetGCD(int a, int b) {
        // 유클리드 호제법
        while(b != 0)
        {
            int rest = a%b;
            a = b;
            b = rest;
        }
        return a;
    }
}
```

## ⏱️ 복잡도
- 시간: O(N log M) - N = 배열 길이, M = 배열 원소 최댓값, 유클리드 호제법이 O(log M)
- 공간: O(1)
