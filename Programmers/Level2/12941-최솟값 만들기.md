# [Lv2] 최솟값 만들기

> **유형:** `#정렬` `#그리디`
> **링크:** [12941](https://school.programmers.co.kr/learn/courses/30/lessons/12941)

## 📝 문제 요약
길이가 같은 배열 `A`, `B` 두개가 있습니다. 각 배열은 자연수로 이루어져 있습니다.
배열 `A`, `B`에서 각각 한 개의 숫자를 뽑아 두 수를 곱합니다. 이러한 과정을 배열의 길이만큼 반복하며, 두 수를 곱한 값을 누적하여 더합니다. 이때 최종적으로 누적된 값이 최소가 되도록 만드는 것이 목표입니다.
배열 `A`, `B`가 주어질 때 최종적으로 누적된 최솟값을 return 하는 solution 함수를 완성해 주세요.

## 💡 접근/풀이 방식
- 최솟값으로 누적되기 위해서는 각각 두 배열에서 최댓값과 최솟값을 꺼내 더하게 하면 된다.
- 위의 방식을 이용하게 위해 `Array.Sort()`로 둘 다 오름차순 정렬 수 `Array.Reverse()`로 한 배열을 역순으로 배치했다.

## 💻 풀이 코드 (C#)

```C#
using System;

public class Solution {
    public int solution(int[] A, int[] B) {
        int answer = 0;
        
        Array.Sort(A);
        Array.Sort(B);
        // 최대 원소와 최소 원소끼리 곱하도록 하나만 역순 배치
        Array.Reverse(B);
        
        for(int i = 0; i < A.Length; i++)
        {
            answer += A[i] * B[i];
        }
        
        return answer;
    }
}
```

## ⏱️ 복잡도
- 시간: O(N log N) - `Array.Sort()`
- 공간: O(1) - `Array.Sort()`의 내부적 요소인 Quicksort의 재귀 호출 스택이 평균 O(log N)이기에 O(log N)으로 평가할 수도 있음
