# [Lv2] 요격 시스템

> **유형:** `#구현` `#정렬` `#그리디`
> **링크:** [181188](https://school.programmers.co.kr/learn/courses/30/lessons/181188)

## 📝 문제 요약
각 폭격 미사일의 `x` 좌표 범위 목록 `targets`이 매개변수로 주어질 때, 모든 폭격 미사일을 요격하기 위해 필요한 요격 미사일 수의 최솟값을 return 하도록 solution 함수를 완성해 주세요.

## 💡 접근/풀이 방식
- 최소로 요격하기 위해선 각각의 포격 시작과 종료지점을 정렬해 둘 필요가 있다.
- 풀이에서는 종료지점을 기준으로 오름차순 정렬을 했고 비교 단계는 반복문에서 포격 시작 기준으로 기준을 잡아둔 종료지점과 비교하여 미사일을 조준하도록 설정했다.

## 💻 풀이 코드 (C#)

```C#
using System;
using System.Collections.Generic; 

public class Solution {
    public int solution(int[,] targets) {
        
        // 정렬용 리스트[포격 시작, 포격 종료]
        List<int[]> list = new List<int[]>();
        for (int i = 0; i < targets.GetLength(0); i++) 
            list.Add(new int[] { targets[i, 0], targets[i, 1] });
        
        // 폭격 종료 지점을 기준으로 오름차순 정렬
        list.Sort((a, b) => a[1].CompareTo(b[1]));
        
        // 맨 처음 요격하는 대상(1)과 첫 폭격 종료 지점(nextFire)
        int answer = 1;
        int nextFire = list[0][1]; 
        
        for (int i = 1; i < list.Count; i++) 
        {
            // 다음 폭격 시작 지점이 기준 잡은 종료 지점보다 작으면 같이 요격 가능
            if (list[i][0] < nextFire)
                continue; 
            // 범위를 벗어나면 다음 미사일로 조준
            nextFire = list[i][1];
            answer++;
        }
        
        return answer;
    }
}
```

## ⏱️ 복잡도
- 시간: O(N log N) - `List.Sort()`가 지배항
- 공간: O(N) — `List<int[]>` 변환, `int[]`는 항상 2인 상수
