## 📝 풀이 양식

각 풀이 파일은 다음 구조를 따릅니다:

- 문제 제목 + 레벨 + 유형 태그 + 문제 링크
- 문제 요약
- 접근 / 풀이 방식
- 코드 (C#, C#을 지원하지 않는 문제일 경우 Java 또는 C++로 작성)
- 시간 / 공간 복잡도

자세한 양식은 [SUBMIT_FORM.md](./SUBMIT_FORM.md) 참고.
