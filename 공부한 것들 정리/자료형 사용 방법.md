# 자료형 사용 방법
## int & 숫자 다루기
- 문자열로 변환하기
  - `int.ToString()`
- 문자열을 숫자로 변환하기
  - C# : `int.Parse()`, null이 들어오면 오류
  - .NET : `Convert.ToInt32()`, null이 들어오면 0을 반환
- 최대/최솟값
  - 최대 : `Math.Max(a, b)`
  - 최소 : `Math.Min(a, b)`
  - *전체가 아닌 두 수 중 최대/최소를 찾는 방식이니 주의*
- 절댓값
  - `Math.Abs(num)`

## char & char[] 다루기
- Parsing 없이 빠르게 형변환 하기
  - `char-'0'`
  - *아스키코드로 0은 '48', 1은 '49'*
- 대소문자 변환
  - 대문자 : `c - 32`
  - 소문자 : `C + 32`
  - *A의 아스키코드는 65, a는 97이고 알파벳 외의 6개는 특수기호*
- char 타입이 정수로 바꿀 수 있는 숫자인지 확인하기
  - `IsDigit(c)`
  - *유니코드 범주에서 숫자인지 확인하는(다른 나라 숫자로 True로 return 할 수 있음) 것이기에 주의가 필요*
  - *안전한 아스키코드만 추출해 비교하는 방식은 `c >= '0' && c <= '9'`*
- char[]로 변환
  - `s.ToCharArray()`
- char[]에서 string으로 합치기
  - `new string(charArray)`
  - Linq 방식으로는 `string.Concat(enumerable)`
 
## string 다루기
- 비교하기
  - `==` 연산자 또는 `Equals()`, C#에서는 둘 다 써도 큰 문제는 없음
- 글자 쪼개기
  - 일반 : `string.Split(' ')`
  - 공백일 때 생기는 빈 문자열 자동 제거 : `string.Split(' ', StringSplitOptions.RemoveEmptyEntries)`
  - *위의 예시는 공백 기준으로 나누기, 나누는 기준이 문자열도 가능*
- 글자 바꾸기/지우기
  - 바꾸기 : `str.Replace("old", "new")`
  - 지우기 : `str.Remove(index, count)`
  - *`Replace()`에서 `"new"` 부분은 공백으로 작성하면 지우는 효과를 볼 수 있음*
  - *`Remove()`는 특정 위치(index)에서부터 몇(count)까지 이동해서 지우는 방식이기에 매개변수 잘 확인하기*
  - *`Remove()`는 새 문자열을 반환하기에 `string result = str.Remove(index, count)` 형식으로 작성해야 함*
- 해당 글자와 일치/포함하는 위치 찾기
  - 왼쪽부터 탐색 : `str.IndexOf('c')`
  - 오른쪽부터 탐색 : `str.LastIndexOf('c')`
  - *만약 문자열 안에 있는 알파벳 중 한 번만 존재하는 걸 찾는다면 둘의 인덱스가 같다는 걸 활용할 수 있음*
- 대소문자 변환
  - 대문자 : `str.ToUpper()`
  - 소문자 : `str.ToLower()`
- new string()
  - char[]나 char*를 string으로 만들 때만 사용
